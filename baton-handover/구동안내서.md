# 구동안내서 — 업무바통 (인수인계 도우미)

> 2026 공공 AI 대전환 챌린지 세션2 · 과제① 업무바통(인수인계) · 양식2 항목 순서로 작성

## 1. 실행 환경
- 운영체제: Windows 10/11 (macOS·Linux도 `run.sh`로 실행)
- 브라우저: Chrome 또는 Edge 최신판 권장(개발 중 Chromium으로 화면 시험). 앱은 이 PC 안에서만 열립니다(`http://localhost:8101`).
- Python 3.10 이상. 설치 첫 화면에서 "Add python.exe to PATH"를 체크합니다. `run.bat`이 버전을 확인하고, Microsoft Store 바로가기는 건너뜁니다.
- 권장 사양: 모델 없이(규칙 기반) 쓰면 일반 사무용 PC로 충분합니다. 내 PC에서 언어모델(Ollama 등)을 함께 돌리면 모델 크기만큼 메모리와 디스크가 더 필요합니다. 공통기반 등 외부 모델 서버에 연결하면 PC 사양 영향이 없습니다.
- 데이터베이스·별도 서버 설치 없음. 처음 실행 때 라이브러리 설치에 인터넷이 필요하고, 이후에는 인터넷 없이 동작합니다(인터넷이 막힌 PC는 4-3 참고).

## 2. 설치·실행 절차
1. 저장소를 내려받아 압축을 풉니다(경로에 한글이 있어도 됩니다).
2. `run.bat`을 더블클릭합니다. 처음에는 실행 환경(.venv)을 만들고 라이브러리를 설치한 뒤 시작합니다.
3. 브라우저에서 **http://localhost:8101** 화면이 자동으로 열립니다. 끝낼 때는 검은 실행 창을 닫습니다.
4. 동작 확인(선택): `python tests/smoke_test.py` — 주요 기능을 자동으로 호출해 통과 여부를 보여 줍니다.

## 3. LLM 연결 설정
- 모델이 없어도 모든 기능이 규칙 기반으로 동작합니다. 모델을 연결하면 문서마다 모델이 항목을 더 찾아 보태고(근거 위치가 실제 원문이 아니면 버림), 업무 개요와 질문 답변을 자연스러운 문장으로 다듬습니다.
- **바꾸는 곳**: 화면 오른쪽 위 **모델 배지**를 눌러 연결 방식·주소·모델 이름을 고르고 "저장"·"연결 확인"을 누릅니다. 설정은 `config.json`에 저장됩니다(예시: `config.example.json`). 환경변수 `LLM_PROVIDER`, `LLM_BASE_URL`, `LLM_MODEL`로도 바꿀 수 있습니다. 코드 수정은 필요 없습니다.
- **API 키 입력 위치**: 키는 화면이나 파일에 적지 않고 환경변수로만 읽습니다(기본 이름 `LLM_API_KEY`, 화면에서 이름 변경 가능). Windows에서는 시작 메뉴 → "계정의 환경 변수 편집" → 새로 만들기로 넣고 앱을 다시 실행합니다.
- **연결 방식**: OpenAI 호환 API(행정안전부 AI 공통기반, vLLM, Ollama `/v1` 등), Ollama 기본 API.
- **지원 모델 계열**: 젬마(Gemma)·라마(Llama)·GPT-OSS·엑사원(EXAONE)·하이퍼클로바X·솔라(Solar). 설정 화면의 "모델 목록 불러오기"로 서버에 실제 등록된 모델 이름을 받아 고릅니다. 계열별 응답 차이(system 역할 미지원, 생각 과정 태그, 추론형 모델의 빈 답)는 자동으로 처리합니다.
- **2종 이상 모델 검증**: Ollama 설치 후 `모델검증.bat`을 실행하면 젬마·엑사원으로 주요 기능을 돌려 `verify_report.md`를 만듭니다. 다른 주소의 모델은 `python tools/verify_models.py --base-url <주소> --models <모델1> <모델2>`.

## 4. 모의데이터와 자료 위치
### 4-1. 모의데이터
- `sample_data/`는 가상의 **공공기관** 기준으로 만든 모의자료입니다. 실제 기관·인물·연락처와 관계없고 민감정보가 없습니다. `tools/samples_baton.py`로 다시 만들 수 있습니다.
### 4-2. 원본 보호와 산출물 위치
- 투입한 원본 파일은 읽기만 합니다. 폴더 경로로 넣으면 그 폴더를 읽기만 하고, 올린 파일은 읽은 뒤 작업 사본을 지웁니다(이름이 든 원문을 남기지 않음).
- 작업 데이터·산출물은 `data/` 폴더에만 저장합니다(설정 `data_dir` 또는 환경변수 `APP_DATA_DIR`로 변경).
### 4-3. 인터넷이 막힌 PC
- 인터넷이 되는 PC에서 같은 버전의 Python으로 `python -m pip download -r requirements.txt -d wheels`를 실행해 만든 `wheels` 폴더를 앱 폴더에 함께 넣으면, `run.bat`이 인터넷 없이 그 파일로 설치합니다.

## 5. 기능 사용 순서(심사용)
1. 실행하면 브라우저가 열립니다(`http://localhost:8101`).
2. **① 올인원 드롭존**에 업무 자료를 종류 구분 없이 몽땅 끌어다 놓습니다(엑셀·한글·PDF·워드·메일·메모장·사진·ZIP·바통 파일, 폴더째도 가능, 여러 번 나눠 놓으면 쌓임). 후임자 착임(발령)일을 고르고 "인수인계 초안 만들기"를 누릅니다. 시연할 때는 드롭존 아래 "파일 없이 시작하기 → 시연용 모의자료"를 고릅니다. 이름은 입력받지 않습니다.
3. **③ D-Day 리스크 레이더**(붉은 카드·120일 타임라인·공공 주기)와 **④ 휴먼 네트워크**(협업 상대·노하우 카드)를 봅니다. 이어 ②에서 담당업무·일정·연락처·현안을 확인합니다. 출처 칩을 누르면 원문 위치가 보입니다. 표 칸을 눌러 고치고 "확인 완료"를 누릅니다.
4. **연간 업무 달력**, **빈틈 스캐너**(자료끼리 다름·빠진 정보·애매한 내용·기한 지남) 탭을 봅니다.
5. **⑤ AI 전임자 분신**에 "11월에 할 일 알려줘", "승강기 업체 연락처"처럼 물어봅니다. 자료에 없는 질문(예: "체육센터 대관료 감면 기준은?")은 지어내지 않고 물어볼 협업 상대(역할)를 알려 줍니다.
6. **후임자 업무매뉴얼**에서 매뉴얼을 만들고 한글(HWPX)·워드로 내려받습니다. 인수인계서도 같은 방식으로 내려받습니다.
7. **연간 업무 달력**의 "내 일정으로 내보내기(.ics)"로 Outlook·그룹웨어 일정 파일을 받습니다(매월·매년 반복, 알림 포함).
8. **②** 화면의 "바통 파일로 저장(.baton)"으로 다음 담당자에게 넘길 파일을 받습니다. 이 파일을 새 인수인계의 자료에 함께 넣으면 계보(1대 → 2대 → 3대 담당자)와 항목·질의응답·노하우·메모가 이어집니다.

## 6. 알려진 제약 사항
- 한글 HWP(5.0) 파일은 본문 글자만 읽으며, 실제 HWP 파일로는 시험하지 못했습니다(HWPX는 시험함). 표·그림 속 글자는 빠질 수 있습니다.
- 스캔한 PDF·사진은 Tesseract·Windows OCR·비전 모델 중 쓸 수 있는 것으로 읽고, 하나도 없으면 '빈틈 스캐너'로 남깁니다.
- 리스크 레이더의 공공 주기(신속집행·행정사무감사 등)는 일반적인 주기입니다. 기관·의회 일정은 화면에서 감사 달·기관 유형을 바꿔 맞춥니다.
- 사람 이름 비식별은 한국어 성씨+이름 꼴과 연락처 표를 기준으로 합니다. 외국인 이름이나 성씨 없이 쓴 별명은 놓칠 수 있어, 처음 넣을 때 화면을 한 번 확인하는 것을 권장합니다.
- 규칙 기반 추출은 공공기관 문서에서 흔한 표현을 기준으로 만들었습니다. 기관마다 표현이 다르면 일부 항목을 놓칠 수 있어 전임자 검토 단계를 둡니다.
- 화면은 이 PC에서만 열리며(127.0.0.1), 다른 웹사이트에서 보낸 요청은 거부합니다. 사용자 구분(일반·관리자)은 시연용 화면 구분이며 로그인·권한 인증은 기관 시스템 연계 시 붙입니다.
- 재배포 제한 라이브러리: 없음. 사용 라이브러리는 python-hwpx(Apache-2.0), lxml·pypdf(BSD-3-Clause), openpyxl·python-docx(MIT), olefile(BSD)입니다. 화면은 외부 라이브러리 없이 직접 작성했습니다.

## 7. 개발 경위 요약
- 개발: 공공기관 【부서·성명】, 2026년 10월.
- 방식: 담당자가 업무 요구사항과 과제 카드(기본·선택기능)를 정하고, AI 코딩 도구로 코드를 작성·수정하는 방식(바이브코딩)으로 개발했습니다. 기능마다 자동 점검(`tests/smoke_test.py`)과 별도의 적대적 검증(예시 밖 입력·보안·원본 보호 시험)을 거쳐 고쳤습니다.
- 설계 원칙: ① 모든 결과에 원문 근거 표시, ② 모델 없이도 전 기능 동작하고 모델은 설정으로 교체, ③ 원본 파일은 읽기만 함, ④ 외부 웹 프레임워크·데이터베이스 없이 파이썬 기본 기능으로 구성해 기관 이관이 쉬움.
- 참고한 공개 개발물: 없음(위 라이브러리 외 전부 직접 작성).
