# 구동 안내서 – 다이수(교육훈련 규정 해석·실적 보고 자동화) 초안

> 제출 시 A4 3~5쪽 PDF로 옮겨 저장하세요. ⟨ ⟩ 부분은 실제 값으로 바꿉니다.

## 1. 실행 환경
- OS: Windows 10/11 (macOS·Linux도 가능)
- 필요 소프트웨어: Python 3.10 이상(https://www.python.org, 설치 시 “Add python.exe to PATH” 체크)
- 브라우저: Edge·Chrome·Whale 최신판
- 사양: 메모리 4GB 이상, 디스크 여유 500MB
- 인터넷: 최초 라이브러리 설치 때만 필요. 막힌 PC는 `오프라인_설치파일_만들기.bat`으로 만든 `wheels` 폴더를 함께 옮기면 인터넷 없이 설치됨. 실행 중 외부 접속 없음

## 2. 설치·실행
1. 공공 GitLab에서 내려받아 압축을 풉니다: ⟨저장소 주소⟩
2. `run.bat`을 더블클릭합니다. 처음 1회는 파이썬 확인 → 전용 실행 환경(.venv) → 라이브러리 설치를 자동으로 합니다(1~2분).
3. 브라우저가 `http://127.0.0.1:8770`을 엽니다(포트가 사용 중이면 다음 빈 포트, 화면에 주소 표시).
4. 처음 화면 **‘샘플로 체험’ → ‘시작하기’** – 모의자료 11개로 전 과정이 바로 시작됩니다(2~3초).
   - 자기 자료: ‘파일·폴더 올리기’에서 파일 또는 폴더 선택(끌어다 놓기 가능), 또는 ‘PC 폴더 경로’ 입력
5. 종료: 검은 창에서 Ctrl+C 또는 창 닫기 (환경 점검: `run.bat --check`)

## 4. 기능 사용 순서(모의자료 기준)
1. **규정·기준**: 넣은 규정 7종에서 읽은 기준 23개와 원문 근거 확인(칩을 누르면 원문). 경고 “내규 목표(60시간)가 정부 권장(80시간)보다 낮습니다”
2. **교육 실적**: 경영평가 지표 6개(1인당 25.4시간, 법정 이수율 75.8%, 필수 66.0%, 1인당 교육비, 만족도 4.04, 예산 집행률 43.7%), 1인당 시간(현재·내규·정부), 분야별 시간, 정부 중점 과제 대비, 직원별 시간(목표 미달 필터), 외부교육 여비·결과보고
3. **법정·필수 현황 → 이수 현황표**: 기한 지난 교육(상반기 안전 12명, 승진자 과정 2명) → 칸을 누르면 판정 근거
4. **확인 필요(3건)**: 동명이인 ‘김민수’, 오타 ‘이영히’, 법정교육처럼 보이는 ‘인권 감수성 향상 예방교육’ 분류
5. **보고서**: 교육훈련 실적 보고서 · 경영평가 지표 실적 · 외부교육 정산 엑셀 · 규정 해석 기준표 · 다음 해 계획(안) · 법정의무교육 이수 현황 보고 · 집합교육 결과보고
6. **일정 짜기 → 교육 운영 → 출석 키오스크**: 교대근무표 기반 회차 → 회차 생성 → 강사 등급(강사수당 기준 문서의 등급) → 실시계획 기안 → 키오스크 서명 → 결과보고·강사료 지급 기안
7. **안내문 · 할 일 · 업무 일정(간트·체크리스트) · 질문하기**
8. **설정**: 국가법령정보 연동(인증키·근거 법령 최신 확인), 결재선, 교육 규칙표(법정교육 기준)

## 5. AI 모델(선택)
- 판정·일정·보고서는 모델 없이 규칙과 계산으로 동작합니다(결과 재현 가능, 근거 추적 가능).
- 모델을 연결하면 질문하기의 지침 답변 문장을 다듬습니다: 설정 → AI 모델 → 프로필(EXAONE·Gemma(Ollama), HyperCLOVA X, OpenAI 호환 서버) → 주소·모델명 → ‘저장 후 연결 확인’.

## 7. 개발 경위(1쪽 이내)
**문제** – 공공기관·공기업 교육담당자의 연간 업무는 “규정이 정한 기준대로 실적을 맞춰 보고서를 쓰는 일”입니다. 그런데 기준은 경영평가 편람, 정부 교육 계획, 회사 교육훈련규정·여비규정, 강사수당 기준에 흩어져 있고, 실적은 사이버교육 엑셀·서명부·수료증·외부교육 대장에 흩어져 있어, 담당자가 규정을 읽고 엑셀로 손수 맞춰 보고서를 씁니다. 규정이 바뀌거나 담당자가 바뀌면 기준부터 다시 찾아야 합니다. ⟨담당자 실제 소요 시간: 예) 실적 집계 연 ○○시간, 경영평가 보고 ○○시간, 여비 정산 ○○시간⟩

**접근(독창성)** – ① **규정 문서를 읽어 계산 기준을 스스로 세웁니다**: 조문(“연간 ○시간 이상”, “수료 후 ○일 이내”)과 표(필수교육 별표, 여비 지급표, 강사수당 등급표, 편람 지표·산식)를 해석하고 값마다 원문 근거를 붙입니다. ② 그 기준으로 법정·필수·직무·외부 교육 기록을 직원 명단과 맞춰 판정·정산·지표를 계산하며, 분자·분모를 그대로 남깁니다. ③ 결과를 실적 보고서·경영평가 지표 실적·정산서·기준표·다음 해 계획(안)으로 씁니다. ④ 기계가 확신하지 못한 것(동명이인·오타·애매한 과정)만 사람에게 묻습니다. 계산은 AI 추측이 아닌 규칙으로 해 결과가 재현되고 감사에서 근거를 댈 수 있습니다.

**확산** – 규정 문서만 바꿔 넣으면 기관마다 기준이 자동으로 바뀌므로 다른 공공기관·공기업에 그대로 쓸 수 있고, 인터넷 없이·설치 한 번으로 동작합니다.
