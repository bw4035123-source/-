# 구동 안내서 – 다이수(법정의무교육 비서) 초안

> 제출 시 A4 3~5쪽 PDF로 옮겨 저장하세요. ⟨ ⟩ 부분은 실제 값으로 바꿉니다.

## 1. 실행 환경
- OS: Windows 10/11 (macOS·Linux도 가능)
- 필요 소프트웨어: Python 3.10 이상(https://www.python.org, 설치 시 “Add python.exe to PATH” 체크)
- 브라우저: Edge·Chrome·Whale 최신판
- 사양: 메모리 4GB 이상, 디스크 여유 500MB
- 인터넷: 최초 라이브러리 설치 때만 필요. 막힌 PC는 `오프라인_설치파일_만들기.bat`으로 만든 `wheels` 폴더를 함께 옮기면 인터넷 없이 설치됨. 실행 중 외부 접속 없음

## 2. 설치·실행
1. 공공 GitLab에서 내려받아 압축을 풉니다: ⟨저장소 주소⟩
2. `run.bat`을 더블클릭합니다. 처음 1회는 파이썬 확인 → 전용 실행 환경(.venv) → 라이브러리 설치를 자동으로 합니다(1~2분).
3. 브라우저가 `http://127.0.0.1:8770`을 엽니다(포트가 사용 중이면 다음 빈 포트, 화면에 주소 표시).
4. 처음 화면 **‘샘플로 체험’ → ‘시작하기’** – 모의자료 11개로 전 과정이 바로 시작됩니다(2~3초).
   - 자기 자료: ‘파일·폴더 올리기’에서 파일 또는 폴더 선택(끌어다 놓기 가능), 또는 ‘PC 폴더 경로’ 입력
5. 종료: 검은 창에서 Ctrl+C 또는 창 닫기 (환경 점검: `run.bat --check`)

## 4. 기능 사용 순서(모의자료 기준)
1. **현황판**: 교육별 이수율·남은 인원·기한 확인 → 빨간 경고 “산업안전보건 정기교육(상반기) 기한 지남 12명”
2. **이수 현황표**: ‘기한 지난 직원’ 필터 → 빨간 칸 클릭 → 판정 근거(예: “사이버 6시간 과정 진도율 80% → 미인정”, “1회차 4시간만 인정, 12시간 중 8시간 부족”)
3. **확인 필요(3건)**: ‘김민수’ 동명이인 → 체육시설팀 김민수로 지정 / ‘이영히’ → 이영희로 지정 / ‘기록관리 실무’ → 의무교육 아님 → 이수 현황에 바로 반영(되돌리기 가능)
4. **일정 짜기**: ‘산업안전보건 정기교육(하반기)’ → 하루에 모으면 참석 불가 인원·최소 인원 미달 팀 vs 다이수 추천 회차 → ‘일정 안내 한글’
5. **안내문**: ‘기한 30일 이내·지난 것’ → 본인 안내문 복사 또는 ‘엑셀(문자 발송용)’, 부서장 통보문 복사
6. **보고·증빙**: 이수 현황 보고서(한글), 이수현황 엑셀, 증빙 묶음 ZIP, 2회차 집합교육 결과보고서(만족도 3.84점, 가장 낮은 문항 ‘시간·장소’, 개선 사항)
7. **교육 운영**: 일정 짜기에서 ‘이 일정으로 회차 만들기’ → 회차 선택 → 강사 이름·등급 입력(강사료·원천징수 자동 계산) → ‘실시계획 기안’ 한글 → ‘출석 키오스크 열기’(새 창, 교육장 입구 노트북·태블릿에 띄움) → 직원이 이름 입력·서명 → ‘퇴실 만족도’ → ‘서명부’(워드, 서명 이미지 포함)·‘결과보고 기안’·‘강사료 지급 기안’
8. **현황판 → 할 일**: 안내 발송·기안·결과보고 시점을 날짜순으로, 문서를 만들면 자동 완료
9. **보고·증빙 → 다음 해 운영계획(안)·교육훈련 실적 집계**
10. **질문하기**: “김민수 뭐 남았어?”, “기간제도 청렴교육 대상이야?”(법 조항 + 기관 지침 문단을 근거로 답)
11. **설정 → 국가법령정보 연동**: 인증키(OC) 입력 → ‘저장 후 연결 확인’ → ‘근거 법령 최신 확인’(조문 원문·시행일자, 개정 시 할 일 알림). 신청 때 등록한 IP·도메인의 PC에서만 응답합니다.
12. **설정 → 강사료 기준·결재선·교육 규칙표**: 기관 실정에 맞게 시간·대상·키워드 수정(저장 즉시 모든 작업에 반영, ‘기본값으로’ 복원)

## 5. AI 모델(선택)
- 판정·일정·보고서는 모델 없이 규칙과 계산으로 동작합니다(결과 재현 가능, 근거 추적 가능).
- 모델을 연결하면 질문하기의 지침 답변 문장을 다듬습니다: 설정 → AI 모델 → 프로필(EXAONE·Gemma(Ollama), HyperCLOVA X, OpenAI 호환 서버) → 주소·모델명 → ‘저장 후 연결 확인’.

## 6. 알려진 제약
- 스캔 PDF(이미지) 수료증은 OCR 미지원, 암호 걸린 문서·.xls·한글97 미지원
- 교육 규칙표의 법정 시간·대상은 2026년 기준 예시이며 기관 담당자가 최신 법령으로 확인해야 함
- 일정 짜기는 근무표가 있는 달 안에서 계산(여러 달은 근무표를 함께 넣기)
- 오픈소스: FastAPI(MIT), Uvicorn(BSD), pypdf(BSD), openpyxl(MIT), olefile(BSD), python-docx(MIT), python-hwpx(Apache-2.0), python-multipart(Apache-2.0)

## 7. 개발 경위(1쪽 이내)
**문제** – 공공기관·공기업 교육담당자는 매년 10여 종의 법정의무교육(성희롱 등 4대폭력 예방, 장애인 인식개선, 청렴, 개인정보보호, 산업안전보건 등)을 직원별로 챙겨야 합니다. 이수 기록은 사이버교육 플랫폼 엑셀, 종이·한글 서명부, 외부 수료증으로 흩어져 있고, 교육마다 대상·시간·주기가 달라 엑셀로 손수 대조합니다. 교대 근무가 많은 시설관리공단은 집합교육 날짜를 잡는 것부터 어렵고, 실적 보고·경영평가 증빙도 따로 모아야 합니다. ⟨담당자 실제 소요 시간: 예) 이수 대조 연 ○○시간, 보고서·증빙 ○○시간⟩

**접근** – ① 형식이 다른 자료를 머리글로 스스로 알아내 한 표로 대조하고, ② 법령 기준을 ‘교육 규칙표’로 분리해 기관마다 고쳐 쓰게 했으며, ③ 기계가 확신하지 못하는 것(동명이인·오타·미분류)만 사람에게 묻고, ④ 교대근무표를 읽어 현장 인원을 지키는 일정을 짜고, ⑤ 안내·보고·증빙까지 바로 쓸 수 있는 한글 문서로 만들었습니다. 판정은 AI 추측이 아닌 규칙과 계산으로 해 결과가 재현되고 감사에서 근거를 댈 수 있습니다.

**확산** – 법정의무교육은 모든 공공기관·공기업에 공통이라 규칙표만 맞추면 그대로 쓸 수 있고, 인터넷 없이·설치 한 번으로 동작해 정보화사업 없이도 바로 적용 가능합니다.
