## 질문 대비
- **AI는 어디에 쓰나?** 판정·일정은 일부러 규칙과 계산으로 했습니다(감사에서 근거를 대야 하므로). 자료 종류 판별, 서명부·수료증 이해, 과정명 분류, 오타 후보 찾기, 만족도 의견 분석이 자동화 부분이고, 연결된 AI 모델은 지침 질문 답변에 씁니다.
- **법령이 바뀌면?** 설정 → 교육 규칙표에서 시간·대상·주기를 바꾸면 모든 판정이 즉시 바뀝니다.
- **다른 기관 양식은?** 머리글 이름(사번·성명·과정명·이수일·서명 등)을 여러 표현으로 받아 줍니다. 다른 이름이면 `sources.py`의 ALIASES에 한 줄 추가.
- **개인정보는?** 내 PC에서만 처리, 외부 전송 없음, 원본은 복사본으로만 처리(지문 비교), 다른 사이트 요청·외부 주소 접속 차단.
- **효과 측정**: ⟨실제 소요 시간 비교표: 이수 대조 / 안내문 / 보고서 / 증빙 – 기존 ○시간 → 다이수 ○분⟩
