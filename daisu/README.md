# 다이수 – 교육훈련 규정 해석·실적 보고 자동화

> 2026 공공 AI 대전환 챌린지 · 세션1 AI 정부 실험실 챔피언십(자유주제) 출품작
> 교육 폴더를 통째로 넣으면 – **규정을 읽어 기준을 세우고, 모든 교육 실적을 계산해, 보고서를 씁니다.**

교육담당자의 연간 업무는 결국 "규정이 정한 기준대로 실적을 맞춰 보고서를 쓰는 일"입니다. 그런데 기준은 경영평가 편람·정부 교육 계획·회사 교육훈련규정·여비규정·강사수당 기준에 흩어져 있고, 실적은 사이버교육 엑셀·서명부·수료증·외부교육 대장에 흩어져 있습니다.

다이수는 이 둘을 한 번에 넣으면

1. **규정을 읽는다** – 문서의 조문과 표에서 계산 기준을 스스로 뽑고 원문 근거를 붙입니다.
   - 교육훈련규정: 1인당 연간 목표 시간, 직급·대상별 **필수교육(별표)**, 위탁교육 결과보고 기한, 1인당 교육비 지원 한도, 교육여비 특례(숙박 제공 시 미지급·일비 감액)
   - 여비규정: 직급군별 일비·식비·숙박비 상한 / 강사수당 기준: 등급별 기본·초과 금액, 원고료
   - 경영평가 편람: 교육훈련 **지표·산식·배점** / 정부 교육 계획: 1인당 권장 시간, 중점 과제 / 예산표
2. **모든 교육을 맞춘다** – 법정의무·필수(내규)·직무·외부(위탁)교육 기록을 직원 명단과 맞춰 분야별 시간, 법정·필수 이수 판정(기한·휴직·승진·신규임용 반영), 외부교육 여비 산정·결과보고 기한·지원 한도를 계산합니다. 동명이인·오타처럼 확신하지 못한 것만 사람에게 묻습니다.
3. **보고서를 쓴다** – 한글(HWPX)·워드·엑셀로
   - **교육훈련 실적 보고서**(총괄·분야별·법정·필수·외부·예산 집행·경영평가 지표·개선 방향·정부 중점 과제 대비)
   - **경영평가 교육훈련 지표 실적**(편람 산식 그대로 + 분자·분모 산출 근거 + 증빙 목록)
   - **외부(위탁)교육 정산 내역**(여비규정으로 산정한 일비·식비·숙박비) · **규정 해석 기준표**(결재 붙임)
   - **다음 해 교육훈련 계획(안)**, 법정의무교육 이수 현황 보고, 집합교육 실시계획·결과보고·강사료 지급 기안
4. 그 밖에 교대근무표를 읽는 집합교육 일정 짜기, 손가락 서명 **출석 키오스크**, 미이수자 안내문, 할 일 목록, 국가법령정보 연동(법령 개정 알림)을 갖췄습니다.

```
 교육 폴더 ──────▶ 규정 해석 ─────────────▶ 실적 계산 ─────────────▶ 보고서
 기록·명단·예산     목표·필수교육·여비·          분야별 시간·이수 판정·          실적 보고·경영평가 지표·
 규정·편람·계획     강사수당·평가 산식(근거)      여비 정산·지표 산출(근거)       정산·기준표·내년 계획
```

## 바로 실행

| 환경 | 방법 |
|---|---|
| **Windows** | `run.bat` 더블클릭 (`실행.bat`도 같음) |
| macOS / Linux | `./run.sh` |
| 직접 실행 | `python run.py` (부족한 라이브러리는 자동 설치) |

- 브라우저가 `http://127.0.0.1:8770`으로 열립니다. 처음 화면에서 **‘샘플로 체험’ → ‘시작하기’**.
- 필요 환경: Python 3.10 이상(3.11·3.13에서 시험), Edge·Chrome·Whale. 인터넷 없이 동작합니다.
- 인터넷이 막힌 PC: 인터넷 되는 PC에서 `오프라인_설치파일_만들기.bat` → 생긴 `wheels` 폴더를 함께 옮기고 `run.bat`.
- 옵션: `--port 9000`, `--check`(환경 점검), `--host 0.0.0.0`(내부망 공유, 이 PC 이름·주소로 오는 접속만 허용).

## 판정 방식(AI가 추측하지 않음)

- **교육 규칙표**(`config/rules.json`, 화면: 설정 → 교육 규칙표): 교육별 근거 법령, 주기(연 1회·반기·채용 시), 시간(직무별 가능: 사무 6 / 현장 12), 기한, 대상(전 직원·개인정보취급자·관리감독자·올해 입사자 등), 과정명 키워드.
  - 기본값은 2026년 기준 예시입니다. **실제 적용 전 최신 법령과 기관 지침으로 확인**하고 고쳐 쓰세요.
- **과정 → 교육 분류**: 과정명 키워드로. 4대폭력 통합교육 4시간은 성희롱·성매매·성폭력·가정폭력 각 1시간으로 나눠 인정.
- **사람 매칭**: 사번 → 이름 → 이름+소속 순. 그래도 모르면 ‘확인 필요’.
- **이수 인정**: 사이버교육은 이수 상태·진도율 100%, 집합교육은 서명이 있는 경우만, 판정 연도·반기 안의 기록만 합산.
- **휴직·퇴사·입사**: 휴직 중이면 ‘휴직(유예)’, 퇴사자는 집계 제외, 기간 이후 입사자는 대상 아님.
- **판정 연도**: 기본은 기준일의 연도. 1~2월에 지난해 실적을 정리할 때는 화면 위 ‘판정 연도’를 지난해로.

## 국가법령정보 연동(선택)

국가법령정보 공동활용(open.law.go.kr)에서 승인받은 인증키(OC)를 **설정 → 국가법령정보 연동**에 넣으면

- **근거 법령 최신 확인**: 교육 규칙표의 근거(예: 산업안전보건법 제29조, 같은 법 시행령 제3조)를 조문 원문·시행일자로 확인하고, **지난 확인 때와 시행일자가 다르면 ‘할 일’에 ‘법령 개정 확인’을 띄웁니다**(규칙표의 시간·대상을 다시 볼 시점).
- **판정 근거에 조문 원문**: 이수 현황표 칸 → 서랍에 조문 원문·시행일·국가법령정보센터 링크
- **질문하기**: 규정 질문에 받아 둔 조문 원문을 함께 표시(질문 응답은 저장본만 사용해 네트워크를 기다리지 않음)

인증키는 `config/settings.local.json`(이 PC에만, 저장소 제외) 또는 환경변수 `LAW_OC`에 저장되고 화면으로 다시 나가지 않습니다. 요청은 `https://www.law.go.kr/DRF`로만 보냅니다(주소 변경 불가). 받은 원문은 `workspace/law_cache.json`에 저장해 인터넷이 끊겨도 마지막 원문을 보여 줍니다. **신청 때 등록한 IP·도메인의 PC에서만 응답**이 오므로, ‘연결 확인’이 실패하면 등록 정보를 확인하세요.

## 강사료·원천징수(설정에서 변경)

- 강사료 기준: 등급별 첫 1시간·추가 1시간 금액, 원고료(1매당) – 기본값은 **예시**이므로 기관 강사료 지급 기준으로 고치세요.
- 원천징수 기본값: 기타소득(필요경비 60% 공제 후 20% + 지방소득세 10%, 기타소득금액 5만원 이하 과세최저한), 사업소득(3% + 0.3%), 내부 직원(근로소득 합산). 세액 10원 미만 버림. 기관 회계 기준으로 확인하세요.

## 공문(기안문) 서식

수신 → (경유) → 제목 → 본문(1. → 가. → 1) → 가)) → 붙임 → 끝. 순서, 하단 결재선(설정 → 결재선). 실시계획·결과보고·강사료 지급·다음 해 운영계획을 이 서식의 한글(.hwpx) 파일로 만듭니다.

## 일정 짜기 규칙(설정에서 변경)

- 교대 근무자는 **주간 근무일**에만 배정(비번·휴무·야간일 호출 없음), 일근 직원은 평일(공휴일 제외)
- 교육 중에도 **팀별로 그날 근무자의 50% 이상은 현장에 남김**, 교육장 정원, 한 사람은 하루 한 회차
- 가장 많은 대상자를 담는 회차부터 고르는 방식이라 결과를 사람이 쉽게 검증할 수 있음
- 배정이 어려운 직원은 사유(근무일 부족·회차 한도)와 함께 따로 보여 주고 사이버교육 안내를 권장

## 보안·운영

- 원본은 복사본으로만 처리하고 처리 전후 지문(SHA-256)을 비교해 표시
- 기본 접속 범위 127.0.0.1, **Host 허용 목록**(DNS 리바인딩 방지), **다른 사이트에서 보낸 요청 차단**(Origin 검사), 변경 요청은 JSON 형식만 허용
- 업로드는 지원 형식만 받고(사진·동영상은 브라우저에서 미리 제외), 경로 조작 차단, 최대 500MB
- AI 모델은 선택 사항(질문하기 문장에만 사용). 내 PC 주소는 프록시를 거치지 않고 연결, API 키는 화면에 다시 보내지 않고 주소가 바뀌면 저장된 키를 지움
- 외부 CDN 없음(폐쇄망 동작)

구성: `daisu/readers.py`(파일 읽기) → `sources.py`(자료 종류 판별·해석) → `regs.py`(규정 해석) → `engine.py`(매칭·판정) → `costs.py`(외부교육 정산) → `kpi.py`(실적·지표) → `annual.py`(연간 보고서) → `schedule.py`(일정) → `reports.py`·`render.py`(보고서·한글/워드) → `sessions.py`(회차·출석·서류) → `fees.py`(강사료) → `gongmun.py`(기안문) → `planning.py`(할 일·실적·운영계획·이력 카드) → `lawapi.py`(국가법령정보) → `qa.py`(질문) → `server.py`(API·보안) → `static/`(화면)
