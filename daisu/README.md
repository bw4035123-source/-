# 다이수 – 법정의무교육 비서

> 2026 공공 AI 대전환 챌린지 · 세션1 AI 정부 실험실 챔피언십(자유주제) 출품작
> "다 이수했나?" – 공공기관·공기업 교육담당자의 법정의무교육 관리 업무를 자료 넣기 한 번으로

직원 명단과 이수 기록(사이버교육 엑셀, 집합교육 서명부, 외부교육 수료증)을 폴더째 넣으면

1. 직원별·교육별 **이수 현황을 법령 기준으로 자동 대조**하고(이수 / 시간 부족 / 미이수 / 휴직 / 대상 아님, 기한 지남 표시)
2. 동명이인·이름 오타·분류 안 되는 과정은 **‘확인 필요’로 모아 사람이 고르게** 하고
3. **교대근무표를 읽어** 비번·휴무일 호출 없이, 현장 최소 인원을 지키는 **집합교육 일정**을 짜고
4. **집합교육 한 회차를 끝까지 처리**합니다: 실시계획 기안 → **출석 키오스크(손가락 서명)** → 퇴실 만족도 → 결과보고 기안 → **강사료·원천징수 계산과 지급 기안**. 출석은 바로 이수로 반영되어 서명부를 다시 입력할 필요가 없습니다.
5. **미이수자 안내문·부서장 통보**, **이수 현황 보고서**, **다음 해 운영계획(안)**, **교육훈련 실적 집계(경영평가 대비)**, **직원별 교육이력 카드**, **증빙 묶음**을 한글(기안문 서식)·엑셀로 만들고
6. 기한·회차에 맞춰 **할 일 목록**(안내 발송 시점, 기안 시점, 결과보고·강사료 기안)을 알려 줍니다.

```
 자료 넣기 ──────▶ 자동 대조 ─────────▶ 확인 필요 ────────▶ 일정 짜기 ─────────▶ 안내·보고·증빙
 명단·이수기록       교육 규칙표(법령)       동명이인·오타        교대근무표 반영          안내문·부서장 통보
 서명부·수료증       시간 합산·나눠 인정      미분류 과정          현장 최소 인원 유지       한글 보고서·엑셀·ZIP
```

## 바로 실행

| 환경 | 방법 |
|---|---|
| **Windows** | `run.bat` 더블클릭 (`실행.bat`도 같음) |
| macOS / Linux | `./run.sh` |
| 직접 실행 | `python run.py` (부족한 라이브러리는 자동 설치) |

- 브라우저가 `http://127.0.0.1:8770`으로 열립니다. 처음 화면에서 **‘샘플로 체험’ → ‘시작하기’**.
- 필요 환경: Python 3.10 이상(3.11·3.13에서 시험), Edge·Chrome·Whale. 인터넷 없이 동작합니다.
- 인터넷이 막힌 PC: 인터넷 되는 PC에서 `오프라인_설치파일_만들기.bat` → 생긴 `wheels` 폴더를 함께 옮기고 `run.bat`.
- 옵션: `--port 9000`, `--check`(환경 점검), `--host 0.0.0.0`(내부망 공유, 이 PC 이름·주소로 오는 접속만 허용).

| 탭 | 하는 일 |
|---|---|
| 자료 | 넣은 파일마다 무엇인지(직원 명단·이수 기록·서명부·수료증·근무표·만족도·지침) 스스로 알아냄, 원본 변경 없음 확인(SHA-256) |

| 일정 짜기 | 남은 대상자를 교대근무표에 맞춰 회차 배정. “하루에 모으면 몇 명 참석 불가·몇 개 팀 최소 인원 미달”과 비교 |

| 출석 키오스크 | 교육장 입구 노트북·태블릿 전체 화면: 이름 입력 → 본인 선택 → 손가락·마우스 서명 → 즉시 이수 반영. ‘퇴실 만족도’로 바꾸면 4문항 5점 척도+의견 |
| 안내문 | 직원별 안내문(남은 교육·시간·기한 D-day), 부서장 통보문, 문자 대량 발송용 엑셀 |
| 보고·증빙 | 이수 현황 보고서, **다음 해 운영계획(안)**(올해 결과·직무별 차이·만족도 의견 → 운영 방향·월별 일정·예산), **교육훈련 실적 집계**(1인당 교육시간, 부서·직무·근무형태별 이수율, 강사료), 이수현황 엑셀, 증빙 ZIP, 올린 서명부별 결과보고서 |
| 연간 계획 | 기한·본인 안내(30일 전)·부서장 통보(14일 전)·집합교육 실시·신규입사자 교육을 12개월에 |
| 질문하기 | “김민수 뭐 남았어?”, “체육시설팀 미이수자”, “기간제도 청렴교육 대상이야?” – 판정 결과·규칙표·기관 지침에서만 답하고 근거 표시 |

## 판정 방식(AI가 추측하지 않음)

- **교육 규칙표**(`config/rules.json`, 화면: 설정 → 교육 규칙표): 교육별 근거 법령, 주기(연 1회·반기·채용 시), 시간(직무별 가능: 사무 6 / 현장 12), 기한, 대상(전 직원·개인정보취급자·관리감독자·올해 입사자 등), 과정명 키워드.
  - 기본값은 2026년 기준 예시입니다. **실제 적용 전 최신 법령과 기관 지침으로 확인**하고 고쳐 쓰세요.
- **과정 → 교육 분류**: 과정명 키워드로. 4대폭력 통합교육 4시간은 성희롱·성매매·성폭력·가정폭력 각 1시간으로 나눠 인정.
- **사람 매칭**: 사번 → 이름 → 이름+소속 순. 그래도 모르면 ‘확인 필요’.
- **이수 인정**: 사이버교육은 이수 상태·진도율 100%, 집합교육은 서명이 있는 경우만, 판정 연도·반기 안의 기록만 합산.
- **휴직·퇴사·입사**: 휴직 중이면 ‘휴직(유예)’, 퇴사자는 집계 제외, 기간 이후 입사자는 대상 아님.
- **판정 연도**: 기본은 기준일의 연도. 1~2월에 지난해 실적을 정리할 때는 화면 위 ‘판정 연도’를 지난해로.

## 강사료·원천징수(설정에서 변경)

- 강사료 기준: 등급별 첫 1시간·추가 1시간 금액, 원고료(1매당) – 기본값은 **예시**이므로 기관 강사료 지급 기준으로 고치세요.
- 원천징수 기본값: 기타소득(필요경비 60% 공제 후 20% + 지방소득세 10%, 기타소득금액 5만원 이하 과세최저한), 사업소득(3% + 0.3%), 내부 직원(근로소득 합산). 세액 10원 미만 버림. 기관 회계 기준으로 확인하세요.

## 공문(기안문) 서식

수신 → (경유) → 제목 → 본문(1. → 가. → 1) → 가)) → 붙임 → 끝. 순서, 하단 결재선(설정 → 결재선). 실시계획·결과보고·강사료 지급·다음 해 운영계획을 이 서식의 한글(.hwpx) 파일로 만듭니다.

## 일정 짜기 규칙(설정에서 변경)

- 교대 근무자는 **주간 근무일**에만 배정(비번·휴무·야간일 호출 없음), 일근 직원은 평일(공휴일 제외)
- 교육 중에도 **팀별로 그날 근무자의 50% 이상은 현장에 남김**, 교육장 정원, 한 사람은 하루 한 회차
- 가장 많은 대상자를 담는 회차부터 고르는 방식이라 결과를 사람이 쉽게 검증할 수 있음
- 배정이 어려운 직원은 사유(근무일 부족·회차 한도)와 함께 따로 보여 주고 사이버교육 안내를 권장

## 보안·운영

- 원본은 복사본으로만 처리하고 처리 전후 지문(SHA-256)을 비교해 표시
- 기본 접속 범위 127.0.0.1, **Host 허용 목록**(DNS 리바인딩 방지), **다른 사이트에서 보낸 요청 차단**(Origin 검사), 변경 요청은 JSON 형식만 허용
- 업로드는 지원 형식만 받고(사진·동영상은 브라우저에서 미리 제외), 경로 조작 차단, 최대 500MB
- AI 모델은 선택 사항(질문하기 문장에만 사용). 내 PC 주소는 프록시를 거치지 않고 연결, API 키는 화면에 다시 보내지 않고 주소가 바뀌면 저장된 키를 지움
- 외부 CDN 없음(폐쇄망 동작)
