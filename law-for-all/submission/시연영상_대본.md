# 시연영상 내레이션 대본

자동 녹화(`scripts/record-demo.mjs`)가 장면마다 아래 문장을 읽습니다. 직접 녹음하실 때도 이 순서대로 읽으면 화면과 맞습니다.

| 장면 | 내용 | 내레이션 |
|---|---|---|
| s00 | 표지 | 법이음은 국민에게는 쉬운 말로, 공직자에게는 정확한 근거로 법을 이어 주는 인공지능 법률 포털입니다. 모든 답변은 국가법령정보센터의 공식 조문을 먼저 찾은 뒤에 만듭니다. |
| s01 | 국민 모드 — 질문 | 첫 화면은 국민 모드입니다. 국민 모드에서는 궁금한 상황을 평소 말투로 물어보면 됩니다. 글이 어려우면 마이크 버튼으로 말해도 됩니다. 퇴사했는데 마지막 월급을 받지 못한 상황을 물어보겠습니다. |
| s02 | 근거 번호·환각 방지 | 답변의 문장마다 근거 조문 번호가 붙습니다. 근거 목록에 없는 조문은 자동으로 지워서, 인공지능이 지어낸 가짜 조문을 막습니다. |
| s03 | 조문 원문 보기 | 번호를 누르면 인공지능의 문장이 아니라, 근로기준법 제삼십육조의 원문이 그대로 열립니다. |
| s04 | 용어 풀이·3단계 | 어려운 법률 용어를 쉽게 풀어 주고, 지금 해야 할 일을 세 단계로 안내합니다. |
| sF1 | 이어서 묻기 | 같은 사안을 이어서 물어볼 수도 있습니다. 기한이 있느냐고 물으면, 근로기준법 제삼십육조에 따라 퇴직 후 십사 일 이내에 지급해야 한다고 조문 원문으로 답합니다. |
| sF2 | 서류 초안 | 필요한 서류는 초안까지 만들어 드립니다. 빈칸을 채우면 임금체불 진정서가 바로 완성되고, 법적 근거는 원문이 확인된 조문만 넣습니다. 입력한 내용은 저장하거나 보내지 않습니다. |
| s05 | 도움받을 곳(전화번호·누리집) | 도움받을 수 있는 곳도 함께 알려 드립니다. 고용노동부 고객상담센터는 국번 없이 천삼백오십, 대한법률구조공단은 백삼십이번으로 바로 전화를 걸 수 있고, 누리집으로도 바로 이동할 수 있습니다. |
| s06 | 판례 실시간 조회(실시간 연결 시) | 비슷한 사건에서 법원이 어떻게 판단했는지, 국가법령정보센터의 판례를 실시간으로 찾아 보여 줍니다. 판례를 누르면 판시사항과 판결요지를 쉬운 설명과 함께 볼 수 있습니다. |
| s07 | 상황 분석실 | 복잡한 상황은 상황 분석실에서 이야기하듯 적으면 됩니다. 사연에 적은 전화번호 같은 개인정보는 서버와 인공지능으로 보내기 전에 자동으로 가리고, 화면에 알려 드립니다. |
| s07b | 사실관계·법령 추천 | 당사자와 금액, 시점을 자동으로 정리하고, 관련 법령을 관련도 순서로 추천합니다. |
| s08 | 변호사·검사·판사 3관점 | 같은 사실을 변호사, 검사, 판사의 시각으로 나누어 검토하고, 판사 관점에서는 법률 요건이 충족되었는지 표로 보여 줍니다. |
| s09 | 글자 크기 | 글자 크기는 세 단계로 키울 수 있어, 어르신도 편하게 읽을 수 있습니다. |
| s10 | 공직자 모드 전환 | 이제 공직자 모드로 바꿔 보겠습니다. 같은 엔진이 실무용 화면으로 바뀝니다. |
| s11 | 검토 보고서 | 검토 결론, 법적 근거 체계, 주요 쟁점, 업무 유의사항, 확인 체크리스트를 보고서 형식으로 정리합니다. |
| sM | 금액 기준·최근 개정 | 공무원 외부강의 사례금 상한을 물으면, 청탁금지법 시행령 별표 원문에 따라 한 시간에 사십만 원, 총액 육십만 원까지라고 답합니다. 최근 일 년 안에 바뀐 조문에는 최근 개정 표시가 붙습니다. |
| sR | 검증 영수증 | 검증 영수증은 답변이 어떤 조문 원문을 언제, 어디서 가져왔는지와 원문 지문, 인용 검증 결과를 한 장으로 남겨, 인공지능을 활용한 행정의 근거가 됩니다. |
| s12 | 보고서 한 번에 작성 | 보고서 한 번에 작성을 누르면, 검토 보고서와 기안문, 민원 회신문, 붙임 네 가지를 동시에 만들고 워드 파일로 저장할 수 있습니다. |
| sC | 공직자 판례·법령해석례 검토(실시간 연결 시) | 공직자 모드의 판례 보기는 업무 분야별 쟁점으로 바로 찾습니다. 행정기관 업무의 기준이 되는 법제처 법령해석례를 먼저 보여 주고, 제목이 쟁점과 맞는 것만 남깁니다. 회답과 이유를 강조해 보여 주고, 검토 보고서에 붙일 요지를 한 번에 복사할 수 있습니다. |
| s13 | 자체규정 점검 — 모의데이터 원클릭 | 자체규정 점검에서는 우리 기관 규정 파일을 끌어다 놓기만 하면 됩니다. 한글, 피디에프, 워드 파일을 브라우저 안에서만 읽고, 서버로 보내지 않습니다. 심사용 모의데이터는 버튼 한 번으로 파일 읽기부터 검증까지 진행됩니다. |
| s14 | 점검 결과 | 상위법령과 조문 단위로 대조해 상충 일곱 건을 찾았습니다. 근거 상위법이 최근 개정된 조항은 따로 알려 줍니다. 판정은 생성형 문장이 아니라, 정해진 기준과 조문 원문으로만 합니다. |
| s15 | 개정안 제안 | 주 사십오 시간 근무는 법정 사십 시간 초과로 표시되고, 수치가 어긋난 조항은 개정안을 자동으로 제안합니다. |
| s16 | 제·개정 지원 | 규정 제개정 지원에서는 바꾸고 싶은 내용을 말하듯 적으면, 신구 조문 대비표와 정합성 점검, 개정 이유와 부칙, 입법 예고문 초안까지 만들어 줍니다. |
| s17 | 법령 뷰어·LLM 교체 | 법령 뷰어에서는 상위법과 시행령, 시행규칙을 세 단으로 대조합니다. 인공지능 모델은 엑사원, 젬마 같은 공공 모델로 설정만 바꿔 교체할 수 있습니다. |
| sE | 정확도 성적표 | 정확도 성적표도 공개합니다. 공공 모델 엑사원이 쓴 처음 보는 질문으로 잰 블라인드 시험은 구십 퍼센트, 근거 밖 인용은 영 건이고, 일부러 섞은 가짜 인용을 모두 걸러냈으며, 누구나 같은 명령으로 다시 확인할 수 있습니다. |
| s18 | 마무리 | 법이음은 다른 기관의 규정과 법령을 데이터로 추가하는 것만으로 범정부로 확산할 수 있습니다. 감사합니다. |

음성 다시 만들기(오프라인 한국어 음성, sherpa-onnx):

```bash
pip install sherpa-onnx soundfile
# 모델: https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-mimic3-ko_KO-kss_low.tar.bz2 (압축 해제)
python3 scripts/tts_narration.py vits-mimic3-ko_KO-kss_low scripts/demo-narration.json dist/narration 0.95
node scripts/record-demo.mjs https://lawon.onrender.com dist/demo.mp4 dist/narration
```
