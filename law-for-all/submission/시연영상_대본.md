# 시연영상 자막 대본

두 영상 모두 `scripts/record-demo.mjs`가 실서비스(https://lawon.onrender.com)를 직접 조작하며 자동 녹화했습니다. 음성 없이 화면 하단 자막으로 설명합니다. AI(업스테이지 Solar Pro 4)가 답을 쓰는 동안 기다리는 구간은 1.2초만 남기고 잘라 냈고, 자막에 실제 걸린 시간을 적었습니다.

| 영상 | 파일 | 길이 | 다시 만들기 |
|---|---|---|---|
| 세션 1(자유주제) | `demo-s1.mp4` | 3분 30초 | `NODE_USE_ENV_PROXY=1 NO_AUDIO=1 TARGET_SEC=210 SESSION=1 node scripts/record-demo.mjs https://lawon.onrender.com dist/demo-s1.mp4` |
| 세션 2(지정과제 ③) | `demo-s2.mp4` | 3분 30초 | `NODE_USE_ENV_PROXY=1 NO_AUDIO=1 TARGET_SEC=210 SESSION=2 node scripts/record-demo.mjs https://lawon.onrender.com dist/demo-s2.mp4` |

## 세션 2 — 규정 제·개정 지원

| 장면 | 화면 | 자막 |
|---|---|---|
| t00 | 표지 | 제정·개정 문서 세트부터 유사 규정 비교, 인용 정정, 상위법 대조까지 · 기관마다 다른 빈칸은 국산 AI가 채우고 가드가 검증 |
| t01 | 제정 입력 → 초안 | ① 제정 — 규정명·종류·상위법 근거 조문·담을 내용 → 조문 체계와 표준 조문 초안(「청탁금지법」 제10조 원문 근거) |
| t02 | 정합성 점검 | 상위 조문 기준(‘10일 이내’) 대조 · 위임 사항 누락 · 위임 없는 의무·벌칙(「지방자치법」 제28조) · 재검토기한 |
| t03 | AI 빈칸 채우기 | 노란 표시가 AI가 채운 자리 — 빈칸 밖 문구를 바꾼 조문은 가드가 버리고 표준 초안 유지, 새 벌칙·근거 밖 인용 차단 |
| t04 | 표준 초안 비교 | 채운 값은 담당자가 확인 — AI 채운 안 ↔ 표준 초안 전환 |
| tL | 한 줄 제정 | “우리 공단 산업안전보건 관리 지침 만들어줘” → 국가법령정보 상위법령 검색 → AI가 조문 구성 설계·조문 작성(가드 검증) → AI 작성안 ↔ 표준 초안 |
| t05 | 유사 규정 찾기 | ② 국가법령정보 행정규칙·자치법규 실시간 검색 → 조문 구성 비교, 우리 초안에 없는 조문 표시 |
| t06 | 빠진 조문 담기 | 담으면 조문 체계·초안·제정이유가 다시 만들어짐 |
| t07 | 문서 세트 | 제정이유·주요내용 · 입법예고문 · 절차 체크리스트 · Word 저장 |
| t08 | 개정 | ③ 개정 의도를 말하듯 → 정해진 문형(‘7일에서 5일로’)은 규칙으로, ‘처리 결과는 전자우편으로도 알릴 수 있도록’은 AI가 개정 조문을 쓰고 가드가 검증 → 신·구조문 대비표 |
| t08b | 정합성 점검·문서 | 기간·금액 변경, 상위법 기준 초과, 규제 신설·강화 표현 점검 → 개정이유(바뀐 항 자동 정리)·부칙·입법예고문 |
| t09 | 조 번호 정리 | ④ 제4조 신설 → 고칠 인용 3건 · 없는 조문 인용 1건 · 정정한 전문(다른 법령 인용은 그대로) |
| tU1 | 상위법 개정 반영 | ⑤ 「근로기준법」 개정 전후 보기 — 국가법령정보 신구법 비교 실시간: 신·구조문 19곳, 용어 ‘근로감독관’→‘노동감독관’ 18곳, 4개 조 삭제(규칙 추출, AI 미사용) |
| tU2 | 영향 점검 → 개정안 | 가상 취업규칙에서 정비 대상 2개 조문(옛 용어·삭제 조문 인용) → 개정안 만들기 → 신구조문대비표·삭제 조문 인용 경고·개정이유 “「근로기준법」 일부개정에 맞추어” |
| t10~t11 | 자체규정 점검 | ⑥ 법정 기준 규칙 약 2초 → AI가 조문마다 국가법령정보 상위 조문과 대조(판정은 더 엄격한 쪽) → 제8조 AI 검토: 1주 45시간 법정 40시간 초과·휴게 미달 |
| t12 | 확산 카드 | 전 기관 공통 · 바로 이관 — 기준·법령은 데이터, 모델 비종속, Python 실행판 |
| t13 | 마무리 카드 | 제정·개정·유사 규정·조 번호 정리·문서 세트·자체규정 점검 요약 |
