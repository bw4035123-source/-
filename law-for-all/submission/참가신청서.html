개요 및 주요 기능
(핵심 요약)

어려운 법률·조례·행정규칙을 국민은 쉬운 말과 해야 할 일로, 공직자는 근거 체계와 공문서 초안으로 받아 보는 법률 포털. 모든 답변은 국가법령정보센터 공식 조문 원문을 먼저 찾아 인용하고, 근거 밖 인용은 자동 제거해 AI의 가짜 조문·판례를 막는다.

  • 국민 모드: 일상 언어 질문 → 문장별 근거 번호가 붙은 쉬운 요약, 용어 풀이, 지금 해야 할 3단계, 기관 연락처, PDF 리포트 / 상황 분석: 사실관계 정리·관련 법령 추천·변호사·검사·판사 3관점 검토
  • 공직자 모드: 검토 결론·근거 체계·쟁점·체크리스트 → 검토 보고서·기안문·민원 회신문·붙임 4종 동시 작성, 상위법–시행령–시행규칙 3단 대조
  • 자체규정 점검: 기관 규정 파일(한글·PDF·Word)을 끌어다 놓으면 근로기준법·청탁금지법·공직선거법·지방공기업법·공유재산법과 조문 단위 대조 → 상충·검토 필요 조항, 근거 조문, 개정안 / 제·개정 지원: 신·구조문 대비표·개정이유·부칙·입법예고문 초안
  • 판례·법령해석례와 법령·행정규칙·자치법규 전체를 법제처 Open API로 실시간 조회(키 없으면 내장 공식 원문 23개 법령으로 자동 대체)
  • LLM 비종속, 인증키·LLM 없이도 전 기능 시연, 문서는 브라우저 안에서만 처리(서버 전송 없음)
