# 모의데이터 — 자체규정 점검 시연용

모두 **가상의 기관 이름으로 새로 쓴 모의 규정**입니다. 실제 기관 자료·개인정보·민감정보는 들어 있지 않습니다.
상위법령 기준과 일부러 어긋나게 쓴 조항이 섞여 있어, 공직자 모드 **자체규정 점검**에 끌어다 놓으면 결과를 바로 확인할 수 있습니다.

| 파일 | 형식 | 기관 유형(화면에서 선택) | 점검 결과(내장 원문 기준) |
|---|---|---|---|
| `가상시설관리공단_복무및보수규정(모의).hwpx` | 한글(HWPX) | 지방공기업 | 상충 7 · 검토 필요 1 · 적합 1 · 참고 2 |
| `가상도시개발공사_임직원행동강령(모의).docx` | Word(DOCX) | 공기업·준정부기관 | 상충 3 · 검토 필요 3 · 적합 1 |
| `가상군_공유재산사용허가운영지침(모의).pdf` | PDF | 지방자치단체 | 상충 3 · 검토 필요 1 · 적합 1 |

## 심어 둔 점검 포인트

**복무 및 보수 규정(HWPX)** — 「근로기준법」
- 1일 9시간·1주 45시간(법정 8시간·40시간), 8시간 근무에 휴게 30분(법정 1시간)
- 시간외근무 1주 16시간(법정 12시간), 가산율 100분의 40(법정 100분의 50)
- 연차 13일(법정 15일), 출산전후휴가 60일(법정 90일)
- 퇴직 금품 21일 이내(법정 14일), 해고 예고 20일 전(법정 30일)
- 규정 개정 시 근로자 의견청취·동의 절차 누락(제94조)

**임직원 행동강령(DOCX)** — 「청탁금지법」·「공직선거법」
- 1회 150만원·연 400만원 수수 허용(법정 100만원·300만원), 직무관련자 금품 허용
- 외부강의 신고 20일 이내(법정 10일), 부정청탁 구두 보고(법정 서면)
- 휴일 선거운동 허용, 홍보·행사 규정에 선거기간 제한 미반영, 강령으로 벌금 부과

**공유재산 사용허가 운영지침(PDF)** — 「공유재산 및 물품 관리법」
- 사용허가기간 8년·자동 갱신(법정 5년, 갱신 절차 필요), 승인 없는 전대 허용
- 수의 사용허가 사유 미한정, 토지 대부기간 10년(법정 5년)
- **현행 법률에 없는 조문(제99조) 인용** → '인용 조문 원문 확인 필요'

## 사용 방법
1. 법이음 실행 → 오른쪽 위에서 **공직자** 모드 선택 → 상단 메뉴 **자체규정 점검**
2. 기관 유형을 표의 값으로 고르고, 파일을 점선 상자에 끌어다 놓기(또는 눌러서 선택)
3. **상위법령과 교차 검증** → 판정별 개수, 조항별 근거 조문, 개정안(현행↔개정안) 확인

`regs.json`은 세 문서의 원문 텍스트(재생성·자동 시험용)입니다.
