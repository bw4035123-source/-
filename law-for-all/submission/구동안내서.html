설치·실행
절차		 ① 주소창에 https://lawon.onrender.com(무료 클라우드라 잠들어 있으면 첫 화면까지 30초~1분) · ② GitLab의 LAW-ON_share.html(또는 웹 바닥글 ‘공유판 내려받기’)을 더블클릭
③ Python 실행판(공공 GitLab 산출물의 law-on-python.zip)
  1. 압축을 풉니다(law-on-python 폴더). Python이 없으면 python.org 에서 3.9 이상 설치(Windows는 ‘Add to PATH’ 선택).
  2. Windows는 run.bat 더블클릭, macOS·Linux는 터미널에서 아래를 실행합니다. 
    cd law-on-python && python3 run.py      # 브라우저가 http://127.0.0.1:8000 을 자동으로 엽니다
  3. 인증키는 따로 입력하지 않습니다(클라우드 서버가 대신 조회). 실행 창에 법령: 실시간 — 법령 API 중계 서버 경유로 표시되고, 화면 상단 배너가 ‘실시간 연동’이면 전체 법령·판례가 실시간으로 조회됩니다.
  4. 연결 점검 python3 run.py --check, 포트 변경 --port 8080 · Node.js판 npm install && npm run dev · Docker docker compose up --build

  1. 흐름 1 · 국민 모드 — 일상 언어 질문 → 근거 있는 쉬운 답 (1분)

    첫 화면 추천 키워드 #층간소음(또는 “퇴사했는데 마지막 월급을 안 줘요” 입력, 마이크 버튼으로 말로 질문하면 자동 검색도 가능) → 법도우미 요약(문장마다 근거 번호) · 어려운 말 풀이 · 지금 해야 할 3단계 · 이런 경우라면(같은 주제의 구체적 상황별 안내) · 도움받을 기관 연락처 → 근거 번호를 누르면 조문 원문이 열림 → 아래 이어서 묻기(“기한이 있나요?” 등, 답도 근거 번호·인용 검증) → 서류 초안(임금체불 진정서 등 7종, 근거 조문 자동 인용) → 검증 영수증(근거 원문 출처·시각·SHA-256 지문) · PDF 법률 리포트.
    이어서 상황 분석 메뉴 → 예시 ‘전세 보증금·연락 두절’(사연에 전화번호를 적으면 자동으로 ○○○ 처리하고 안내) → 법령 추천 · 3관점 분석: 사실관계 자동 정리, 관련 법령 순위, 변호사·검사·판사 관점과 요건 충족표.

  2. 흐름 2 · 공직자 모드 — 검토 보고서 한 번에 (1분)

    오른쪽 위 공직자 전환(첫 화면으로 이동) → 해시태그 #부정청탁금지법 → 검토 결론·근거 체계·쟁점·유의사항·체크리스트 → “공무원 외부강의 사례금 상한은?” 입력 → 시행령 별표 원문으로 1시간당 40만원(총액 60만원), 근거 카드의 ‘최근 개정 2026.6.30’ 표시 → 검증 영수증(조문별 최종 개정일) → 보고서 한 번에 작성: 검토 보고서·기안문·민원 회신문·붙임 4종 동시 작성, 인용문 복사·Word 저장 → 법령 뷰어에서 상위법–시행령–시행규칙 3단 대조 → 판례·법령해석례 검토(업무 분야별 쟁점, 법제처 유권해석 우선, 검토보고서용 요지 복사).

  3. 흐름 3 · 공직자 모드 — 자체규정 점검 → 개정안 (1분)

제약 사항
  • 실시간 전체 법령·판례는 법제처 국가법령정보 Open API로 조회합니다. 법제처는 인증키에 등록된 서버 IP에서만 응답하므로 실행판은 인증키·등록 IP를 가진 법이음 클라우드 서버를 중계로 사용합니다(인증키는 서버에만 있고 PC·파일에는 없음). 인터넷이 막힌 환경 등에서 중계 서버에 연결되지 않으면 내장 30개 법령으로 자동 대체하고 화면에 표시하며, 판례를 만들어 보여 주지 않습니다. 직접 호출하려면 LAW_PROXY_URL=off와 등록 IP의 인증키를 사용합니다.
  • 자체규정 점검의 판정은 정해진 기준(근로시간·연차·금품 한도·임원 임기·사용허가기간 등)과 조문 원문으로만 하며, 현재 대조 법령은 5종(근로기준법·청탁금지법·공직선거법·지방공기업법·공유재산법)입니다. 최종 판단은 소관 부처 해석 확인이 필요합니다.
  • 상황 분류는 독립 작성자 블라인드 시험 기준 90%(엄격 채점 85%)입니다. 분류되지 않은 질문은 전체 법령 실시간 검색으로 답하므로, 내장 토픽보다 쉬운 설명·행동 안내가 적을 수 있습니다. 개인정보 가림은 형식이 정해진 번호만 대상이며 이름·주소는 가리지 않습니다(입력 화면에 적지 않도록 안내).
  • 음성 질문은 브라우저 내장 음성 인식을 씁니다. 크롬·엣지는 음성을 브라우저 제공사 서버에서 글로 바꾸며, 지원하지 않는 브라우저(일부 파이어폭스 등)에서는 마이크 버튼이 보이지 않습니다. 법이음 서버에는 인식된 글만 개인정보를 가린 뒤 전달됩니다.
  • 스캔 이미지 PDF(글자 정보 없음), 배포용·암호 한글 문서, 예전 Word(.doc)는 읽을 수 없으며 안내 문구를 표시합니다.
  • LLM 답변 품질은 연결 모델에 따라 다르며, 근거 밖 인용은 자동 제거됩니다. 소형 모델은 인용 조문은 맞아도 문장 해석이 부정확할 수 있어 답변 옆에 조문 원문 카드를 항상 함께 표시하고, 금액·기간이 원문과 다르면 규칙기반 답변으로 대체합니다. 본 서비스는 법률 정보 제공이며 법률 자문이 아닙니다.

문제 인식

법은 국민 생활 곳곳에 닿아 있지만 조문은 어렵고, 생성형 AI는 그럴듯한 가짜 조문·판례를 만들어 공공 서비스에 바로 쓰기 어렵습니다. 공직자는 민원 회신·검토 보고서를 쓸 때마다 근거 조문을 찾아 옮겨 적고, 기관의 취업규칙·행동강령·재산관리 규정이 상위법 개정을 따라가지 못해 감사·노사 분쟁에서 지적되는 일이 반복됩니다.

접근 방식

① 근거부터 찾고 답은 나중에 — 질문을 토픽·조문 검색으로 먼저 연결해 공식 원문을 확보하고, AI에는 그 조문만 주며 문장마다 근거 표식을 붙이게 했습니다. 근거 목록 밖 인용은 서버에서 지우고, 형식이 깨지면 규칙기반 답변으로 바꿉니다. 근거 카드에는 AI 문장이 아니라 법령 원문만 보여 줍니다.

② 한 엔진, 두 개의 화면 — 같은 근거를 국민에게는 쉬운 말·3단계 행동·기관 연락처로, 공직자에게는 검토 결론·근거 체계·체크리스트·공문서 서식으로 보여 줍니다.

③ 기관 규정까지 확장 — 한글·PDF·Word 규정 파일을 브라우저 안에서 읽어 조문 단위로 상위법과 대조하고(수치 기준·허용 조항·인용 조문 실재 여부), 개정안과 신·구조문 대비표까지 이어지게 했습니다. 판정은 생성형 문장이 아니라 정해진 기준과 원문으로 합니다.

④ 바로 옮겨 쓸 수 있는 구조 — LLM은 어댑터로 분리해 폐쇄망 Ollama(EXAONE·Gemma 등)부터 OpenAI 호환 서버까지 설정만으로 교체하고, 인증키·LLM이 없어도 동작하게 했습니다. 정보화사업 이관을 고려해 Next.js(TypeScript)판과 추가 설치 없는 Python 실행판을 함께 두고, 두 엔진의 결과가 같은지 자동 시험으로 확인합니다(TypeScript 시험 161건, Python 시험 42건).

⑤ 성능은 숫자로, 틀린 것도 공개 — 정확도 성적표를 누구나 재현할 수 있게 만들고, 규칙 조정에 쓰지 않은 블라인드 결과와 틀린 문항을 그대로 공개했습니다. 개발자가 쓴 문항은 편향이 있어, 로컬 EXAONE 3.5가 쓴 독립 문항으로 다시 재고(71.7% → 86.4% → 90.0%), 개선 중에는 다음 문항을 열어 보지 않았습니다. 실제 심사 관점의 질문으로 점검하며 찾은 오류(구어 해고·보증금 질문, 공무원 겸직·행정처분 사전통지·개인정보 목적 외 이용 근거 등)는 고치고 회귀 시험에 추가했습니다.

기대 효과·확산

국민은 상황을 말하기만 하면 근거와 할 일을 한 화면에서 얻고, 공직자는 근거 조사·보고서 초안·규정 점검을 한 곳에서 처리합니다. 대조 법령과 점검 기준은 데이터로 분리돼 있어 기관별 규정(복무·보수·감사·계약 등)과 법령을 추가하는 방식으로 다른 기관·업무에 그대로 확산할 수 있습니다.
