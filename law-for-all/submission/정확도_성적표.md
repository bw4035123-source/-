## 2차 블라인드에서 틀린 질문(고치지 않고 기록)

- 아이들이 집에서 뛰면 몇 데시벨부터 문제인가요 — 기대: floor-noise / 결과: 토픽 없음 → 실시간 전체 법령 검색
- 집주인이 바뀌었다는데 제 보증금은 안전한가요 — 기대: jeonse-fraud / 결과: deposit-return
- 회식 후 집까지 조금 운전했는데 단속됐어요 — 기대: drunk-driving / 결과: 토픽 없음 → 실시간 전체 법령 검색
- 팀장이 내일부터 출근하지 말라고 했어요 — 기대: unfair-dismissal / 결과: 토픽 없음 → 실시간 전체 법령 검색
- 쇼핑몰에 제 정보를 지워 달라고 요청하려면 — 기대: privacy-access / 결과: 토픽 없음 → 실시간 전체 법령 검색
- 과태료 부과가 억울한데 다툴 방법이 있나요 — 기대: admin-appeal / 결과: 토픽 없음 → 실시간 전체 법령 검색
- 업체 대표가 명절 선물로 한우를 보냈어요 — 기대: anti-graft / 결과: 토픽 없음 → 실시간 전체 법령 검색

※ 블라인드 문항을 보고 규칙을 고치면 더 이상 블라인드가 아니므로, 개선 후에는 새 문항으로 다시 잰다(1차 76.2% → 개선 → 2차 측정).
