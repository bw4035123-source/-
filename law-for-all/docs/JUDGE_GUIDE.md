# 「법이음」 예선 심사위원용 구동안내서

> 소요 시간: 설치 약 2분 + 시연 약 10분 · API 키 불필요

## 1. 제출물 구성

| 항목 | 위치 |
|---|---|
| 소스코드 | 저장소 `law-for-all/` 전체 |
| 설명서 | `README.md`(개요·아키텍처·설정), 본 문서(구동·시연 절차) |
| 환경설정 예시 | `.env.example` (비밀값 없음, 실제 키는 저장소에 포함하지 않음) |
| 배포 구성 | `Dockerfile`, `docker-compose.yml`, `.gitlab-ci.yml` |
| 테스트 | `tests/` (Vitest 44개) |
| 라이선스 | `LICENSE` (MIT) |

공공 GitLab 등록 시 `law-for-all/` 폴더를 저장소 루트로 올리면 `.gitlab-ci.yml`이 자동으로 타입검사·린트·테스트·빌드를 수행합니다. `.gitignore`에 `.env*`, `node_modules`, 빌드 산출물이 제외되어 있어 인증키가 등록되지 않습니다.

## 2. 원클릭 로컬 실행

| 환경 | 실행 |
|---|---|
| **Python만 있는 PC(권장)** | `law-on-python.zip` 압축 해제 → `실행.bat`(Windows) 또는 `python run.py` → http://127.0.0.1:8000 |
| Windows | `start.bat` 더블클릭 → 브라우저 자동 열림 |
| macOS / Linux | `./start.sh` |
| Node.js 직접 | `npm install` → `npm run dev` |
| Docker | `docker compose up --build` |

접속: **http://localhost:3000**  · 상태 확인: http://localhost:3000/api/health

> Node.js가 없다면 https://nodejs.org 에서 LTS(20 이상)를 설치하세요. 처음 실행 시 패키지 설치(약 1~2분) 후 바로 시작합니다.

## 3. 13분 시연 시나리오

### ① 국민 모드 (3분)
1. 메인 화면에서 추천 키워드 **`# 층간소음`** 클릭
2. 확인할 점
   - 말풍선 요약의 **번호 배지(1·2·3)** → 클릭 시 오른쪽에서 **조문 원문 슬라이드 뷰어**가 열림
   - '어려운 말, 쉽게 풀어볼게요' 용어 카드, **3단계 행동 가이드**(단계별 근거 조문 표시)
   - 상단 **`근거 검증 통과 · 인용 N건`** 배지 클릭 → 검증 방식 설명
   - **PDF 법률 리포트 다운로드** → '인쇄 · PDF로 저장' → 대상 'PDF로 저장'
   - '도움받을 수 있는 곳'의 전화 바로걸기(모바일)
3. 직접 입력 예: `주택임대차 보증금 돌려받으려면?`, `육아휴직 급여는 얼마나 받을 수 있나요?`

### ② 공직자 모드 (4분)
1. 헤더의 **국민 ↔ 공직자** 토글을 전환 (검색 결과 화면에서 바로 전환 가능)
2. 추천 키워드 **`# 부정청탁금지법`** 클릭(해시태그: 근로기준법 · 지방공기업법 · 공직선거법 · 부정청탁금지법 · 공유재산법)
   - **법령 검토 요약 보고**(검토 결론·법적 근거 체계·주요 쟁점·유의사항·체크리스트)
   - **기안문 인용문 복사** → 메모장에 붙여넣기: `관련 근거 / 가. 「부정청탁 및 금품등 수수의 금지에 관한 법률」 제8조(…)` 형식 확인
   - 근거 카드의 **인용문 복사** 버튼(조문 단위)
3. 근거 카드 → 슬라이드 뷰어 → **법령 전문·3단 대조** 클릭 (또는 `법령 둘러보기 → 주택임대차보호법`)
4. (`LAW_API_OC` 설정 시) **법령 둘러보기**에서 **행정규칙**·**자치법규** 탭 → `층간소음` 검색 → 고시·조례 원문, 국민 모드에서 `반려견 목줄 안 하면 과태료 있나요` → 「동물보호법」 조문 인용
   - **조문 본문**: 법제처 형식, 조문 목차, 조문별 `기안문 인용` / `「」 표기` / 링크 복사
   - **3단 대조**: 법률 제8조 ↔ 시행령 제10조·제11조 위임 관계 대조
   - **제·개정 이유**, **실무 노트·판례** 탭

### ②-1 AI 법률 상황 분석실 — 변호사·검사·판사 (3분, 국민 모드 전용)
1. 헤더 **상황 분석** 클릭(모바일은 둘째 줄 버튼) → 예시 **`전세 보증금·연락 두절`** 선택 → **법령 추천 · 3관점 분석**
2. 확인할 점
   - **사실관계 정리**: 임대인·임차인, 2억5천만원, 지난달, 경매 진행 등 자동 추출 / 쟁점 2개(전세사기·보증금 반환) 동시 발견
   - **추천 관련 법령**: 핵심·관련·참고 등급과 '왜 추천했는지' 사유, 클릭 시 원문 슬라이드
   - **AI 모의 법정**: 변호사(권리·증거·전략) / 검사(사기죄 성립 가능성·법정형) / 판사(요건 5개 ↔ 사실 대조표, 예상 판단 방향)
   - 우측 상단 **쟁점 전환** 버튼으로 '보증금 반환' 쟁점의 3관점 보기
3. 예시 **`퇴사 후 월급 미지급`**: 검사 관점에 근로기준법 제109조(벌칙)·반의사불벌 표시, 판사 요건 3개 모두 '확인됨'
4. 예시 **`층간소음 갈등`** 후 문장을 '화장실 물소리'로 바꾸면 판사 요건이 '불충족 가능'으로 바뀌는 것 확인

### ②-2 판례 보기 (1분, `LAW_API_OC` 설정 시 실시간)
1. 국민 모드에서 `회사에서 갑자기 해고됐어요` 검색 → 아래 **"비슷한 사건, 법원은 어떻게 판단했을까요?"**에 실제 판례 목록
2. **판례 보기** 클릭 → 판시사항·판결요지·전문, **인용 표기 복사**
3. 상단 메뉴 **판례 보기** → `임차보증금` 검색

### ②-2-1 자체규정 점검 (2분, 공직자 모드 전용)
1. 상단 **자체규정 점검**(모바일은 둘째 줄 **규정 점검**) → 예시 **`○○도시공사 취업규칙`** → **상위법령과 교차 검증**
2. 확인할 점
   - 상단 집계: **상충 7 · 검토 필요 2** (판정 칸을 누르면 해당 조문만 보기)
   - 제10조: `1주 44시간` → 근로기준법 제50조 40시간 초과, `4시간마다 20분` → 제54조 30분 미달, **개정안** 대비(44→40, 20분→30분)
   - 제15조 연차 12일(제60조 15일 미달), 제12조 가산 100분의 30(제56조), 제2조 '법령에 우선' 조항(제96조), 제30조 개정 절차에 근로자 의견청취 누락(제94조)
   - 제31조: `「근로기준법」 제150조` 인용 → 실시간 연결 시 **존재하지 않는 조문 인용(상충)**, 내장 원문 모드에서는 '원문 확인 필요'
   - 근거 조문 칩 클릭 → 원문 슬라이드 / **보고서 복사** · **Word 저장**
   - 보유한 규정 파일(한글 HWP·HWPX, PDF, Word DOCX)을 입력 영역에 **끌어다 놓으면** 조문을 자동으로 불러옴(파일은 서버로 전송되지 않음)
3. 예시 **`○○공사 임직원 행동강령`**: 연간 500만원 경조사비 허용(청탁금지법 제8조), 외부강의 30일 신고(제10조), 선거운동 허용(공직선거법 제60조·제85조), 과태료 조항
4. 예시 **`○○시설관리공단 공유재산 관리규정`**: 사용허가 10년·자동 연장(공유재산법 제21조), 전대 허용(제20조), 토지·건물 대부 7년(제31조), 이사장 임기 2년(지방공기업법 제59조)

### ②-3 공직자 실무 문서·규정 제·개정 (2분, 공직자 모드 전용)
1. 공직자 모드에서 `# 근로기준법` → **보고서 한 번에 작성** → 부서·담당자 입력 → 검토 보고서·기안문·민원 회신문·붙임 탭 확인 → **4종 한 파일로 저장**(Word)
2. 상단 **제·개정 지원** → `민원 처리에 관한 법률 시행령` / `제14조` → 개정 방향 `14일에서 10일로 단축` → **개정안 작성** → 신·구조문 대비표·정합성 점검·입법예고문 확인

### ③ 접근성·반응형 (1분)
- 헤더의 **가 / 가+ / 가++** (글자 크기)
- 브라우저 폭을 줄이거나 휴대폰으로 접속해 모바일 레이아웃 확인

### ④ AI 구조·LLM 비종속성 (2분)
- 상단 메뉴 **서비스 구조** → 답변 파이프라인, LLM 공급자 상태, 내장 데이터 현황, 환각 방지 장치
- 헤더 **AI 모델** 드롭다운: 키가 없는 공급자는 '(미설정)'으로 비활성 표시

## 4. API 키 설정 (선택)

```bash
cp .env.example .env.local     # Windows: copy .env.example .env.local
```

| 목적 | 설정 |
|---|---|
| 법제처 국가법령정보 실시간 원문·행정규칙·자치법규·판례 | `LAW_API_OC=발급받은OC` (open.law.go.kr 신청, 실행 PC의 공인 IP 등록). Python 실행판은 `키설정.bat` |
| OpenAI | `OPENAI_API_KEY=sk-...` |
| Anthropic Claude | `ANTHROPIC_API_KEY=...` |
| Upstage Solar 등 OpenAI 호환 | `OPENAI_BASE_URL=https://api.upstage.ai/v1` `OPENAI_API_KEY=...` `OPENAI_MODEL=solar-pro` |
| 로컬 LLM(Ollama) | `ollama pull exaone3.5:7.8b` 후 `OLLAMA_MODEL=exaone3.5:7.8b` |

설정 후 서버를 재시작하면 됩니다. 실시간 연결 시 근거 카드에 **`실시간`** 배지가, 법령 뷰어에 **'국가법령정보 실시간 원문'** 표시가 나타나고, 공직자 모드에 관련 판례·법령해석례가 조회됩니다. 연결에 실패하면 자동으로 내장 데이터로 대체되고 안내 문구가 표시됩니다.

## 5. LLM 2종 이상 스위칭 테스트

**방법 1 — 화면에서 실시간 전환**
1. `.env.local`에 두 공급자 이상 설정(예: `OPENAI_API_KEY` + Ollama 실행)
2. 서버 재시작 → 헤더 **AI 모델** 드롭다운에서 공급자 선택
3. 같은 질문을 검색해 결과 상단 배지(예: `OpenAI · gpt-4o-mini`, `Ollama(로컬 LLM) · exaone3.5:7.8b`)로 실제 응답 모델 확인

**방법 2 — 명령어로 일괄 비교**
```bash
npm run llm:check
npm run llm:check -- "전세사기 예방" citizen
```
출력 예:
```
● 규칙기반 엔진(LLM 없음)   응답 규칙기반 엔진(law-rule-engine-v1) · 4ms · 인용 3건 · 검증 통과
● OpenAI                    응답 OpenAI(gpt-4o-mini) · 3120ms · 인용 3건 · 검증 통과
● Ollama(로컬 LLM)          응답 Ollama(exaone3.5:7.8b) · 8410ms · 인용 3건 · 검증 통과
○ Anthropic Claude          건너뜀 — ANTHROPIC_API_KEY 필요
```

**방법 3 — 기본값 변경**: `.env.local`의 `LLM_PROVIDER=ollama`(또는 `openai`, `anthropic`) 한 줄 수정 후 재시작

**방법 4 — Docker 폐쇄망 구성**: `docker compose --profile local-llm up --build` (Ollama + EXAONE 자동 내려받기, 이후 드롭다운에서 'Ollama(로컬 LLM)' 선택)

npm run check    # 타입검사 + 린트 + 테스트 44개

## 7. 문제 해결

| 증상 | 조치 |
|---|---|
| `3000` 포트 사용 중 | `npx next dev -p 3001` |
| 실시간 법령이 안 나옴 | `python run.py --check`(Python) 또는 결과 화면 안내 문구 확인 — '인증 실패'면 open.law.go.kr 에 이 PC 공인 IP 등록. 실패 시에도 내장 데이터로 계속 동작 |
| Ollama가 '(미설정)' | `ollama serve` 실행 여부, `OLLAMA_MODEL` 이름이 `ollama list` 결과와 같은지 확인 |
| LLM 답변 대신 규칙엔진 답변 | 결과 상단 ⓘ 안내에 사유 표시(키 오류·시간 초과·검증 실패 시 안전하게 대체) |
