> **2026년 공공 AI 대전환 챌린지 · 세션 1 출품작**
> 복잡하고 어려운 법률·조례·행정규칙을 **국민과 공직자 누구나** 쉽게 찾고, 해석하고, 바로 활용하는 AI 법률 지능형 포털

### 3분 만에 보기
1. **국민 모드** — 추천 키워드 `#임금체불` → 문장마다 근거 번호가 붙은 쉬운 요약 → 번호를 누르면 조문 원문 → 지금 해야 할 3단계 → **이어서 묻기**("기한이 있나요?"·"어디에 신고하나요?" — 답도 근거 번호·인용 검증) → **서류 초안**(임금체불 진정서·보증금 내용증명·부당해고 구제신청서 등 7종, 근거 조문 자동 인용) · **검증 영수증**(근거 원문 출처·시각·SHA-256 지문·인용 검증 결과)
2. **공직자 모드**(오른쪽 위 전환) — `#부정청탁금지법` → 검토 결론·근거 체계·체크리스트 → **보고서 한 번에 작성**(검토 보고서·기안문·민원 회신문·붙임)
3. **자체규정 점검**(공직자 모드) — **‘모의데이터로 바로 체험’** 버튼 한 번(한글·Word·PDF 모의 규정 내장, [`submission/mock-data/`](submission/mock-data/)와 같은 파일) → 상충·검토 필요 조항, 근거 조문, 개정안

시연영상·구동안내서·참가신청서·모의데이터는 [`submission/`](submission/)에 있습니다.

## 1. 바로 실행

| 방법 | 설치 | 비고 |
|---|---|---|
| ① 웹 접속 **https://lawon.onrender.com** | 없음 | 가장 간단. 판례·실시간 법령 |
| ② 공유판 `release/LAW-ON_share.html` | 없음 | 더블클릭하면 서버 없이 열림(웹 바닥글 ‘공유판 내려받기’로도 받음) |
| ③ Python 실행판 `release/law-on-python.zip` | Python 3.9+ | 폐쇄망·기관 내부 설치, LLM 교체 시험(`--llm-test`) |
| ④ Node.js·Docker | Node 18.18+ | 개발·정식 구축 |

②·③도 판례·실시간 법령은 법이음 클라우드 서버(법령 API 중계)를 거쳐 받으므로 **실행하는 PC에 인증키·IP 등록이 필요 없습니다**(인증키는 서버에만 있음). 연결이 안 되면 내장 원문 23개 법령 + 규칙기반 엔진으로 동작합니다.

### 🐍 Python 실행판 (Node.js 불필요)
`law-on-python.zip` 압축을 풀고 **Python 3.9 이상**으로 실행합니다. `pip install` 없이 표준 라이브러리만 사용합니다.

```bash
python run.py        # Windows는 실행.bat / run.bat 더블클릭 → http://127.0.0.1:8000
```

- 화면은 Next.js 정적 빌드, API(검색·질의응답·상황분석·환각 가드·LLM 어댑터·법령 Open API)는 Python으로 이식(`python/law_for_all/`)
- **TypeScript 엔진과 결과 동일성 테스트**(38개 입력에 대해 응답 JSON 완전 일치) 포함, Python 3.9~3.13 검증
- 배포판 다시 만들기: `node scripts/build-python.mjs` → `dist/law-on-python.zip`

### Node.js 실행판 (3가지 방법 중 하나)

필요 환경: **Node.js 18.18 이상**(20 LTS 권장). API 키·인터넷 없이도 모든 화면이 동작합니다.

```bash
# 방법 A — 원클릭
./start.sh          # macOS / Linux
start.bat           # Windows (더블클릭)

# 방법 B — npm
npm install
npm run dev         # → http://localhost:3000

# 방법 C — Docker
docker compose up --build                       # → http://localhost:3000
docker compose --profile local-llm up --build   # + 로컬 LLM(Ollama, EXAONE 3.5) 함께 구동
```

프로덕션 실행: `npm run build && npm start`

## 2. 주요 기능

### 국민 모드 (Easy & Warm)
- 일상 언어 질문 → **말풍선 요약**(문장마다 근거 번호), **어려운 용어 풀이 카드**, **지금 해야 할 3단계 행동 가이드**
- **관련 기관 연락처**(검수된 고정 데이터, 전화 바로걸기) · **PDF 법률 리포트**(브라우저 인쇄 → PDF 저장, 한글 깨짐 없음)
- 추천 키워드: 층간소음 · 전세사기 예방 · 보증금 반환 · 육아휴직 급여 · 민원 처리 기한 · 임금체불 · 음주운전 · 정보공개

### 공직자 모드 (Pro & Accurate)
- 공직자 핵심 법령 해시태그: **근로기준법 · 지방공기업법 · 공직선거법 · 부정청탁금지법 · 공유재산법** (취업규칙 기준, 임원 임기·추천, 선거 중립, 금품수수 한도·외부강의 신고, 사용허가·대부기간)
- **행정 요약 보고서**(검토 결론 → 법적 근거 체계 → 주요 쟁점 → 업무 유의사항 → 확인 체크리스트)
- **법제처 형식 조문 뷰어**(`/laws/[id]`): 조문 목차, 조문별 앵커 링크, 위임 조문 바로가기
- **상위법령–시행령–시행규칙 3단 대조**(위임 관계 기준, 2단계 위임까지 추적)
- **제·개정 이유**, **실무 쟁점 노트**, **판례·법령해석례 실시간 조회**(Open API 연동 시)
- **기안문 인용문 복사**: `「주택임대차보호법」 제3조(대항력 등)에 따르면, "…"라고 규정하고 있음.` / '관련 근거 가. 나. …' 블록 / 보고서 전문 복사

### AI 법률 상황 분석실 (`/analyze`) — 변호사·검사·판사 3관점 *(국민 모드 전용)*
- 겪은 일을 자유롭게 서술하면 **사실관계 자동 정리**(당사자·행위·금액·시점·장소) → **법률 쟁점 발견**(복합 쟁점 최대 3개) → **관련 법령 추천 순위**(핵심/관련/참고 + 추천 사유 + 관련도 막대)
- **AI 모의 법정**: 같은 사실을 세 법률가의 시각으로 검토
  - **변호사**(내 편): 주장할 권리·근거, 준비할 증거, 대응 전략
  - **검사**(공익): 위법·범죄 성립 가능성, 적용 제재(형법 사기·경범죄 인근소란·근로기준법 벌칙 등). 형벌 조항이 근거에 없으면 그렇다고 명시
  - **판사**(중립): 쟁점 정리, **법률 요건 ↔ 사실관계 대조표**(확인됨/확인 필요/불충족 가능), 예상 판단 방향(가능성 표현)
- 예시 상황 5종, 검색 결과에서 바로 이어보기, 분석 결과 텍스트 복사, 모바일은 역할별 탭
- 모든 관점 문장에 조문 인용, LLM 사용 시에도 동일한 인용 화이트리스트 가드 적용(가짜 조문·요건 근거 자동 제거)

### 공직자 실무: 보고서 한 번에 작성
- 공직자 모드 검색 결과에서 **보고서 한 번에 작성** → **검토 보고서 · 기안문(내부결재 서식) · 민원 회신문 · 붙임(조문 원문)** 4종을 동시에 작성
- 검증된 답변·근거 조문 원문·관련 판례만 공문서 서식(가. 나. / 1) 2) / 붙임 / 끝.)에 배치, 보고서체·회신문체 자동 변환
- 부서·담당자·연락처 입력(브라우저에만 저장), 편집 후 복사 · Word(.doc, 한글 호환) 저장 · 인쇄 · 4종 한 파일 저장

### 법제처 Open API 전체 법령 연동 (`LAW_API_OC`)
- **법령 둘러보기**(`/laws`): **법령**(법률·대통령령·총리령·부령) · **행정규칙**(훈령·예규·고시) · **자치법규**(조례·규칙) 탭에서 국가법령정보 전체를 실시간 검색 → 원문 전문 뷰어
- **토픽 밖 질문도 전체 법령에서 근거 검색**: 질문 → 검색어 추출(조사·어미 제거, 생활어→법령 용어) → 법령명 검색 + 본문 검색(드문 말 가중치, 여러 말 AND 검색) → 상위 법령 본문 조회 → 질문과 맞는 조문을 인용 카드로
  - 예: "반려견 목줄 안 하면 과태료?" → 「동물보호법」 제16조·제101조, "청소년에게 술 팔면?" → 「청소년 보호법」 제28조, "건축허가 받으려면?" → 「건축법」 제11조
- 인증키가 없거나 호출이 실패하면 내장 핵심 법령 23종(국가법령정보센터 원문 스냅샷)으로 자동 대체하고 화면에 안내

### 자체규정 점검 (`/compliance`) *(공직자 모드 전용)*
- 기관 유형(공기업·준정부기관 / 지방공기업 / 지방자치단체 / 기타)을 고르고 기관 규정 **파일을 끌어다 놓으면**(한글 HWP·HWPX, PDF, Word DOCX) **조문 단위로 상위법령과 대조** — 직접 붙여넣기도 가능
  - 문서 텍스트 추출은 **브라우저 안에서만** 처리(파일을 서버로 보내지 않음). 스캔 이미지 PDF·배포용(열람 제한)·암호 문서는 안내 메시지 표시
- 대조 법령: 「근로기준법」 · 「부정청탁 및 금품등 수수의 금지에 관한 법률」 · 「공직선거법」 · 「지방공기업법」 · 「공유재산 및 물품 관리법」
- 점검 항목
  - **근로기준법**: 1주 40시간·1일 8시간, 연장근로 1주 12시간, 휴게시간, 연차 15일, 가산수당 50%, 해고예고 30일, 출산전후휴가 90일, 퇴직 금품 14일, '법령보다 우선' 조항, 취업규칙 변경 시 의견청취·불이익 변경 동의
  - **청탁금지법**: 1회 100만원·연 300만원 초과 허용, 직무관련자 금품 허용, 외부강의 신고 10일, 부정청탁 서면 신고
  - **공직선거법**: 선거운동·정치활동 허용 조항, 홍보·기공식·행사 규정의 선거기간 제한 미반영
  - **지방공기업법**: 임원 임기 3년·1년 단위 연임, 임원추천위원회 추천 절차
  - **공유재산법**: 사용허가기간 5년·자동 연장·갱신, 수의 허가 사유, 전대 금지, 대부기간(토지·정착물 5년)
  - **인용 조문 검증**: 기관 규정이 인용한 「법령」 제N조가 현행 법령에 실제로 있는지(실시간 원문 연결 시 전체 조문 기준), 약칭·띄어쓰기 차이 자동 연결
  - 기관 규정으로 형벌·과태료를 정한 조항
- 판정: **상충 / 검토 필요 / 적합 / 참고** — 정해진 기준과 조문 원문으로만 판정(생성형 문장으로 위반을 단정하지 않음), 근거 조문 클릭 시 원문 슬라이드
- 수치 위반은 **개정안 자동 제안**(현행↔개정안 대비), **교차 검증 결과 보고서**(보고서체) 복사·Word 저장
- 예시 규정 3종: ○○도시공사 취업규칙, ○○공사 임직원 행동강령, ○○시설관리공단 공유재산 관리 위탁 규정

### 규정 제·개정 지원 (`/drafting`) *(공직자 모드 전용)*
- 대상 조문 선택(또는 자체 규정·조례 붙여넣기) + 개정 방향을 말하듯 입력(예: `7일에서 5일로 단축`, `‘민원인’을 ‘신청인’으로 변경`, `‘…’ 삭제`, `신설: ③ …`)
- **개정안 자동 작성 → 신·구조문 대비표**(삭제·밑줄 표시) → **정합성 점검**(기간·금액 변경, 상위법 기한·상한 초과 가능성, 존재하지 않는 조문 인용, 규제 신설·강화 표현)
- **개정이유·주요내용 · 부칙 · 입법예고문 · 제·개정 절차 체크리스트**(법령/자치법규/행정규칙별) 초안, 대비표 포함 Word 저장
- 법령 뷰어의 조문마다 **개정안 작성** 바로가기

### 판례 보기 (`/cases`) — 국민·공직자 공통
- 질문·상황 분석 결과 아래에 **관련 판례·법령해석례**가 자동 표시(답변은 먼저, 판례는 별도로 불러와 속도 저하 없음)
- 항목을 누르면 **판례 뷰어**: 판시사항 · 판결요지 · 참조조문 · 참조판례 · 판결 전문(법령해석례는 질의요지 · 회답 · 이유), 국민 모드에는 각 항목의 쉬운 설명
- **인용 표기 복사**(예: `대법원 2026. 1. 29. 선고 2023두54914 판결`), 국가법령정보센터 원문 링크
- 판례만 따로 찾는 **판례 보기** 메뉴(사건명 검색 → 부족하면 본문 검색으로 보완)
- 법제처 국가법령정보 Open API(`LAW_API_OC`)로 실시간 제공 — 확인되지 않은 사건번호·판결 내용을 만들어 보여 주지 않음

### 공통
- 근거 조문 카드 클릭 → **원문 전문 슬라이드 오버 뷰어** + 위임 관계로 연결된 상·하위법령 조문
- 접근성: 글자 크기 3단계(어르신 배려), 키보드 탐색·스킵 링크, 스크린리더 레이블, 움직임 줄이기 설정 존중

### 환각(Hallucination) 방지 설계
1. LLM에는 **검색된 근거 조문만** 제공하고 문장마다 `[[조문키]]` 인용을 강제합니다.
2. 근거 목록 밖 인용은 **서버에서 자동 제거**, 인용이 하나도 없거나 JSON 형식이 깨지면 **답변을 폐기하고 규칙엔진으로 대체**합니다.
3. 본문의 `「법령」 제N조` 표현을 근거 원문과 **대조**해 확인되지 않으면 화면에 '확인 필요'로 표시합니다.
4. 근거 카드에는 AI 문장이 아닌 **법령 원문만** 표시하고 국가법령정보센터 원문 링크를 제공합니다.
5. 기관 연락처는 LLM이 만들지 않으며, 근거가 없으면 **LLM을 호출하지 않습니다**.
6. 시연 데이터에는 확인되지 않은 판례 사건번호를 넣지 않고, 판례는 Open API 실시간 조회로만 제공합니다.

## 4. 환경설정

`.env.example`을 `.env.local`로 복사해 필요한 값만 넣습니다. **아무 값도 없어도 동작합니다.**

| 변수 | 설명 | 기본값 |
|---|---|---|
| `LAW_API_OC` | 법제처 국가법령정보 Open API 인증키(OC). [open.law.go.kr](https://open.law.go.kr)에서 신청하고 실행하는 PC·서버의 공인 IP 등록. 넣으면 **법령·행정규칙·자치법규·판례 전체 실시간 조회** | (비움 → 내장 핵심 법령 23종) |
| `LAW_PROXY_URL` | 법령 API 중계 서버 주소 — 비우면 법이음 클라우드 서버(lawon.onrender.com) 경유, `off`면 위 인증키로 www.law.go.kr 직접 호출 | (비움) |
| `LAW_PROXY_TOKEN` | (선택) 중계 서버에 `PROXY_TOKEN`을 설정한 경우 같은 값 | (비움) |
| `LLM_PROVIDER` | 기본 LLM: `mock` · `openai` · `anthropic` · `ollama` | `mock` |
| `OPENAI_API_KEY` / `OPENAI_MODEL` / `OPENAI_BASE_URL` | OpenAI 또는 OpenAI 호환 서버(Upstage Solar, vLLM, LM Studio 등) | `gpt-4o-mini`, `https://api.openai.com/v1` |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | Anthropic Claude | `claude-sonnet-5-5` |
| `OLLAMA_BASE_URL` / `OLLAMA_MODEL` | 로컬·폐쇄망 LLM | `http://localhost:11434`, `exaone3.5:7.8b` |
| `LLM_TIMEOUT_MS` | LLM 응답 제한시간 | `45000` |

API 키는 서버(Route Handler)에서만 사용되며 브라우저로 전달되지 않습니다(`server-only` 모듈 보호).

## 5. LLM 스위칭 (2종 이상 테스트)

```bash
# 예) Ollama 로컬 모델 + OpenAI 를 함께 설정
ollama pull exaone3.5:7.8b          # 또는 gemma3:4b, llama3.1:8b, solar 등
cat >> .env.local <<'ENV'
OPENAI_API_KEY=sk-...
OLLAMA_MODEL=exaone3.5:7.8b
ENV

npm run llm:check                    # 설정된 모든 공급자로 같은 질문 → 결과·검증 상태 비교
python3 python/run.py --llm-test ollama:gemma3:4b,ollama:exaone3.5:7.8b   # Python판: 모델별 구동 검증 → LLM_검증결과_날짜.md
npm run llm:check -- "질의민원 처리기간" officer
```

- **기본값 변경**: `LLM_PROVIDER=ollama` 한 줄 수정 후 재시작
- **실시간 전환**: 화면 상단 `AI 모델` 드롭다운(설정된 공급자만 활성화) — 답변 상단 배지에 실제 응답한 모델이 표시됩니다.
- **새 공급자 추가**: `lib/llm/providers/`에 `LLMProvider` 구현 1개 + `registry.ts` 등록 1줄

## 7. 유의사항

본 서비스는 **법률 정보 제공** 목적이며 개별 사안에 대한 법률 자문이 아닙니다. 내장 시연 데이터는 주요 조문을 발췌·요약한 것으로, 실제 업무에는 `LAW_API_OC`를 설정해 법제처 국가법령정보 Open API의 현행 원문을 사용하십시오.

## 법령 API 중계 서버(FastAPI)

브라우저가 국가법령정보센터를 직접 부르면 IP 차단이 일어나므로, 인증키를 서버에만 두고 실시간 조회를 중계하는 FastAPI 서버를 `proxy/`에 제공합니다. 기본 구성에서는 법이음 Python 서버(lawon.onrender.com)의 `/api/raw` 중계를 쓰며, 별도 중계 서버를 두고 싶을 때 `LAW_PROXY_URL`로 이 FastAPI 서버를 지정합니다. 실행·테스트·Cloudflare Tunnel 공개 방법은 [proxy/README.md](proxy/README.md)를 보세요.
