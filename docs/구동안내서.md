# [양식2] 구동 안내서 – 업무바통 (초안)

> 제출 시 A4 3~5쪽 PDF로 옮겨 `[구동안내서]_기관명_팀명.pdf`로 저장하세요. ⟨ ⟩ 부분은 실제 값으로 바꿉니다.

## 실행 환경
- OS: Windows 10/11 (macOS·Linux도 가능)
- 필요 소프트웨어: Python 3.10 이상(https://www.python.org, 설치 시 “Add python.exe to PATH” 체크)
- 브라우저: Edge·Chrome·Whale 최신판
- 권장 사양: 메모리 8GB 이상(로컬 LLM 사용 시 16GB 이상·GPU 권장), 디스크 여유 1GB
- 인터넷: 최초 패키지 설치 때만 필요(폐쇄망은 `wheels` 폴더 동봉본 사용). 실행 중 외부 접속 없음

## 설치·실행 절차
1. 공공 GitLab에서 저장소를 내려받아 압축을 풉니다: ⟨https://gitlab.aigov.go.kr/…/baton⟩
2. 폴더 안의 `실행.bat`을 더블클릭하거나, 명령창에서 `python run.py`를 실행합니다. (처음 1회 필요한 패키지를 자동 설치, 1~2분)
3. 브라우저가 자동으로 `http://127.0.0.1:8765`를 엽니다. 열리지 않으면 주소를 직접 입력합니다.
4. 처음 화면 오른쪽 **‘✨ 샘플로 체험’ → ‘바통 받을 준비 시작’**을 누르면 모의데이터로 전 과정이 시작됩니다(약 5초).
   - 직접 자료로 시험하려면 ‘📁 폴더 올리기’로 폴더를 선택하거나 ‘🖥 PC 경로’에 폴더 경로를 입력합니다.
5. 종료: 검은 창에서 Ctrl+C 또는 창 닫기

(환경 점검: `python run.py --check` / 포트가 사용 중이면 다음 빈 포트로 자동 실행되며 화면에 주소가 표시됨)

## LLM 연결 설정
- 기본값은 **오프라인 규칙엔진**(LLM 없이 동작)이라 별도 설정 없이 모든 기능을 시연할 수 있습니다.
- 모델 연결: 화면 오른쪽 위 **⚙ 설정 → AI 모델**에서 사용할 프로필을 고르고 주소·모델명·API 키를 입력한 뒤 ‘저장’.
  - 로컬(Ollama): `ollama pull exaone3.5:7.8b` 후 프로필 `ollama-exaone` 선택(주소 `http://localhost:11434/v1`)
  - HyperCLOVA X: 프로필 `hyperclova-x`에 CLOVA Studio API 키 입력(또는 환경변수 `CLOVA_STUDIO_API_KEY`)
  - 그 밖의 OpenAI 호환 서버(vLLM 등): 주소와 모델명만 바꾸면 됨
- 키 저장 위치: `config/settings.local.json`(이 PC에만 저장, 저장소에 포함되지 않음)
- 실행 옵션으로 교체: `python run.py --model ollama-gemma`
- **이식성 입증**: 설정 화면 ‘전체 모델 자가진단’ → 모델별 ①한국어 응답 ②JSON 출력 ③출처 인용 시험 결과 표
  - ⟨시험한 모델 2종 이상과 결과를 여기에 기재, 예: EXAONE 3.5 7.8B ✔, Gemma 3 12B ✔⟩

## 기능 사용 순서(핵심 흐름)
1. **자료 → 초안**: 샘플로 체험 → ① 자료 탭에서 파일별 성격(공식문서·메일·개인메모), 가린 민감정보 수, ‘원본 보호 확인’ 표시를 확인
2. **전임자 검수 → 인터뷰**: ② 초안 검수에서 아무 출처 칩을 눌러 원문 위치 확인 → ✔/✏ → ③ 암묵지 인터뷰에서 ‘기한이 자료마다 다릅니다’ 질문에 답변 → 인수인계서·달력에 ‘전임자 구술’로 반영되고 불일치가 해소됨
3. **후임자 수령**: ④ 업무 달력 → ⑤ 협업 지도(사람 클릭) → ⑥ 질문하기(“수준진단 증빙은 어디에 있어?”, “이번 달 기한이 있는 일은?”, 자료에 없는 질문 → ‘전임자에게 보내기’) → ⑦ 첫 30일 → ⑧ 바통 터치(전임자 확인 → 후임자 수령) → Word 내려받기

## 알려진 제약 사항
- 스캔 PDF(이미지)는 OCR 미지원, 암호 걸린 HWP·배포용 문서는 미리보기 텍스트만 추출, .xls·한글97 미지원
- 규칙엔진의 인식 결과는 전임자 검수를 전제로 함(LLM 연결 시 문장 품질 향상)
- 한 번에 올릴 수 있는 자료 최대 500MB
- 오픈소스: FastAPI(MIT), Uvicorn(BSD), pypdf(BSD), openpyxl(MIT), olefile(BSD), python-docx(MIT), python-multipart(Apache-2.0) – 재배포 제한 구성요소 없음

## 개발 경위 요약(1쪽 이내)
**문제 인식** – 인사이동 때 작성하는 인수인계서에는 일정·협의 관계·진행 상황 같은 실제 노하우가 빠지고, 자료는 개인 PC에 한글·엑셀·PDF·메일로 흩어져 있어 후임자는 과거 문서를 다시 찾고 주변에 물어가며 업무를 처음부터 익힙니다. 특히 노하우가 빠지는 이유는 ‘쓸 시간이 없어서’보다 ‘무엇이 빠졌는지 본인도 모르기 때문’이라고 보았습니다.

**접근 방식** – ① 자료를 폴더째 읽어 출처가 달린 초안을 자동으로 만들고(작성 부담 제거), ② 자료끼리 날짜가 다르거나 결론이 없는 부분을 기계가 찾아 전임자에게 질문하게 하여(빠진 것을 찾아 주는 인터뷰), ③ 후임자가 묻는 질문 중 자료로 답할 수 없는 것은 다시 전임자에게 돌려보내는 순환 구조를 만들었습니다.
공공 현장 적용을 위해 LLM 없이도 동작하는 규칙엔진을 기본으로 두고, OpenAI 호환 API로 행정안전부 AI 공통기반 지원 모델(Gemma·Llama·GPT-OSS·EXAONE·HyperCLOVA X·Solar)을 자유롭게 교체하도록 설계했습니다. 원본 읽기 전용(해시 검증), 민감정보 자동 가림, 외부 CDN 없는 화면 등 보안 기본값을 갖추고, 기관 양식·프롬프트는 설정 파일로 분리해 정보화사업 이관이 쉽도록 했습니다.
