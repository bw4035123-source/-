# 시연 대본: 업무바통 (약 5분)

모델 없이(오프라인 규칙엔진) 진행해도 모든 장면이 동작합니다. 숫자는 함께 넣은 모의자료 기준입니다.

**준비**
- `run.bat` 실행 → 브라우저 `http://127.0.0.1:8765`
- 이전 시연 기록을 지우려면 `workspace/` 폴더를 비웁니다.
- 영상 녹화 시 브라우저 확대 110%, 창 너비 1280 이상 권장

## 질문 대비
- **모델 2종 검증**: `모델검증.bat` 결과 `verify_report.md`를 보여 줍니다(날짜·전화번호가 원문과 맞는지까지 대조).
- **환각 방지**: 모델이 쓴 문장의 근거 ID를 원문과 대조하고, 근거가 없으면 빨간색 ‘근거 없음’으로 두어 전임자가 확인해야만 문서에 들어갑니다.
- **보안**: 원본 읽기 전용(SHA-256 비교), 비밀번호·주민번호·휴대전화·계좌번호 가림 후에만 모델에 전달, 기본 접속 127.0.0.1, 외부 CDN 없음.
- **폐쇄망**: `오프라인_설치파일_만들기.bat`으로 만든 `wheels` 폴더만 옮기면 인터넷 없이 설치됩니다.
- **정보화사업 이관**: 파서·추출·모델·저장소·내보내기가 모듈로 나뉘어 있고, 양식·프롬프트·모델은 설정 파일로 바꿉니다. 자료 넣는 부분(`ingest.py`)만 문서시스템 API로 바꾸면 인사발령 시 자동 초안도 가능합니다.
- **민감정보**: 모의자료의 인물·기관·연락처는 모두 가상입니다.
