# 국무총리상(세션2 대상) 전략 메모

대상 = **과제별 1위 3팀 중 최고 득점**. 즉 업무바통 1위만으로는 부족하고, 서무비서·규정 에이전트 1위보다 점수가 높아야 합니다.

## 1. 심사 기준과 업무바통의 대응
| 지표(배점) | 심사위원이 볼 것 | 업무바통의 근거 | 시연·문서에서 강조할 것 |
|---|---|---|---|
| 활용성(40) | 실제 행정 현장에서 쓸까, 전 기관 공통인가, 기관별 설정 | 인사이동은 모든 기관에서 1년에 2번 반복. 양식·항목·키워드·프롬프트를 설정으로 바꿈 | “우리 과 인수인계서 양식으로 바꾸는 데 1분” 화면, 기대효과 숫자(아래) |
| 완성도(30) | 핵심 기능, 안정적 구동, 사용 편의 | 기본 기능 3개 + 선택 기능 6개 모두 구현, LLM 없이도 동작, 자동 시험 15개 | 구동안내서대로 5초 만에 샘플 시연, 오류 없이 끝까지 |
| 확산 용이성(30) | 특정 LLM 비종속, 정보화사업 이관 | OpenAI 호환 계층, 모델 자가진단 표, 규칙엔진 폴백, Docker, 외부 CDN 없음 | **2종 이상 실제 모델 자가진단 표 캡처**를 구동안내서에 첨부 |

## 2. 남은 할 일(우선순위)
1. **실제 모델 2종 이상 구동 입증** (확산 용이성 30점의 핵심)
   - Ollama 설치 → `ollama pull exaone3.5:7.8b`, `ollama pull gemma3:12b` → 설정에서 자가진단 → 표 캡처
   - 가능하면 HyperCLOVA X(CLOVA Studio)도 1종 추가 → “로컬 + 국산 API” 조합
   - 실제 모델로 샘플 초안을 만들어 보고 문장 품질·속도 확인(프롬프트는 `config/prompts`에서 다듬기)
2. **실제 한글 파일로 확인**: 한글에서 저장한 `.hwp`와 `.hwpx` 모의 문서를 하나씩 넣어 텍스트가 잘 나오는지 확인
   - 샘플 HWPX는 파서 시험용 최소 구조라 한글 프로그램에서 열리지 않을 수 있음 → 한글로 다시 저장한 파일로 교체 권장
3. **모의데이터 보강**: 본인 업무와 비슷한 가상 자료(민감정보 없이)를 10~20개로 늘리면 시연 설득력↑
4. **기대효과 수치화**(활용성): 예) 인수인계서 작성 4시간 → 30분(초안+검수), 후임자 적응 기간 단축, 연 2회 × 전 공무원
   - 동료 2~3명에게 써 보게 하고 소요 시간을 재서 “실측” 수치로 쓰면 더 강력
5. 제출물: 참가신청서(양식1), 구동안내서(양식2, `docs/구동안내서.md` 초안), 시연영상(5분), GitLab 등록(비공개, 주제 ‘2026 공공 AI 대전환 챌린지 세션2’)
   - **11. 11. 마감 후 GitLab 수정 불가** – 최소 하루 전 최종본 등록

## 3. 시연영상 5분 구성안
| 시간 | 장면 | 한 줄 메시지 |
|---|---|---|
| 0:00–0:30 | 인사발령 문자 → 흩어진 폴더 | “인수인계서엔 노하우가 없다” |
| 0:30–1:10 | 폴더째 투입, 원본 보호·민감정보 가림 | “넣기만 하면 된다, 원본은 안전하다” |
| 1:10–2:10 | 초안 검수: 출처 칩 → 원문 형광펜, 신뢰 신호등 | “모든 문장에 근거가 있다” |
| 2:10–3:00 | **불일치 탐지 → 암묵지 인터뷰 답변 → 자동 반영** | “빠진 걸 AI가 찾아서 물어본다” (가장 강조) |
| 3:00–4:10 | 후임자: 달력·협업 지도·“이번 달 기한?”·자료에 없는 질문 → 전임자에게 | “후임자는 첫날부터 일한다” |
| 4:10–4:40 | 바통 터치 → Word 내려받기 | “결재에 바로 첨부” |
| 4:40–5:00 | 설정: 모델 교체·자가진단 표 | “어떤 모델로도, 어느 기관에서도” |

## 3-1. 차별화 기능으로 바꾼 시연 순서(추천)
1. 샘플 투입 → 화면 상단 **바통 낙하 위험도 85점(위험)** – “이대로 인사이동하면 이만큼 위험합니다”
2. 불일치·결론 없는 현안 인터뷰 답변 → **점수가 실시간으로 떨어짐** (85 → 35) – 가장 강력한 장면
3. 후임자: AI 전임자 분신에게 질문 → 모르는 건 진짜 전임자에게 넘김
4. 인수 리허설 → 인수 준비도 % → 바통 터치
5. 마지막: **바통 계보 1대 → 2대 → 3대** – “사람은 바뀌어도 업무 지식은 남습니다”

## 4. 결선 발표 포인트
- 첫 문장: “인수인계서가 부실한 건 성의가 없어서가 아니라, **무엇이 빠졌는지 본인도 모르기 때문**입니다.”
- 차별점 3가지만: ①출처 각주 ②암묵지 인터뷰(빠진 것을 찾아 묻는 AI) ③질문 바구니(인사이동 후에도 이어지는 인수인계)
- 정보화사업 연계: 문서시스템(온나라 등) API 연계 시 폴더 투입 대신 자동 수집 → 인사발령 시 자동 초안
